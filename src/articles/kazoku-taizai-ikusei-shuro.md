家族滞在で日本に住む外国人をアルバイトとして雇っている会社の中には、フルタイムでの雇用を考えているところもあるでしょう。家族滞在は、親や配偶者の扶養を受けて暮らすための[在留資格](../zairyu-shikaku-visa-difference/#zairyu-shikaku)です。フルタイムで働くには、仕事に合った在留資格に変える必要があります。

この記事では、2027年4月1日に始まる[育成就労](../ikusei-shuro/)と、現在取得できるほかの在留資格を、本人の状況ごとに説明します。2026年11月23日時点で公表されている情報をもとにしています。

## 家族滞在のままフルタイムで働ける？

家族滞在では、原則として働けません。資格外活動許可（包括許可）を受けた人は、原則として週28時間まで働けます。勤め先が複数ある場合は、合計で週28時間までです。資格外活動許可（包括許可）を受けていても、風俗営業などに関する一定の仕事はできません。

週28時間を超えて働くには、原則として在留資格の変更が必要です。変更を申請しただけではフルタイムで働き始めることはできません。変更が許可されてから勤務を始めます。

週28時間以内の勤務でも注意が必要です。家族滞在は、親や配偶者の扶養を受けていることが前提の在留資格です。親や配偶者の扶養から外れ、自分の収入で生活するようになった場合は、家族滞在のままでいられなくなる可能性があります。

## 家族滞在から育成就労に変更できる？

出入国在留管理庁の育成就労制度Q&Aは、ほかの在留資格から育成就労に変更できる場合があるとしています。家族滞在からの変更も可能性はありますが、具体的な条件はまだ公表されていません。

変更の流れは次のとおりです。

1. 受け入れる会社が外国人一人ひとりの育成就労計画を作成し、外国人育成就労機構の認定を受ける
2. 本人が認定通知書などを添えて、現在の在留期間が満了する前に在留資格の変更を申請する

制度が始まる前の2026年9月1日から、外国人技能実習機構が育成就労計画の認定申請を受け付けています。

計画の認定を受けても、在留資格の変更が必ず許可されるわけではありません。これまでの在留状況や育成就労への変更の必要性などを踏まえて審査されます。

育成就労は原則3年間働きながら特定技能1号に必要な技能を身につける制度です。特定技能1号を取得するには原則として技能試験に合格する必要がありますが、育成就労はまだ必要な技能を身につけていない人にとっても選択肢になる可能性があります。

学歴は問われませんが、育成就労を始める時点で18歳以上であることなど、本人にも要件があります。受け入れる会社にも、次のような要件があります。

- 任せる仕事が育成就労の対象分野（育成就労産業分野）に当たる
- [受入れ人数枠](../ikusei-ninzu-waku/)の上限を超えない
- 技能を習得するための育成体制が整っている

## 日本の高校を卒業した人は「定住者」「特定活動」を検討

日本の高校を卒業しただけでは、「[技術・人文知識・国際業務](../gijinkoku/)」（技人国）などの学歴要件を満たさない場合があります。そこで出入国在留管理庁は、親の扶養を受けながら日本で暮らしてきた人のための取扱いを設けています。高校などを卒業して日本で就職する場合、要件を満たせば「定住者」か「特定活動」に変更できます。育成就労とは違い、働ける分野は限られていません。

変更に必要な主な要件は次のとおりです。

| 要件 | 定住者 | 特定活動 |
|---|---|---|
| 日本の小学校と中学校（義務教育）を修了している | 必要 | 不要 |
| 日本の高校などを卒業している（卒業見込みを含む） | 必要 | 必要 |
| 入国時に18歳未満だった（日本で生まれた人も対象） | 必要 | 必要 |
| 入国後、継続して家族滞在で在留している（※） | 必要 | 必要 |
| 就職先が決まっている（内定を含む。その職場で週28時間を超えて働く場合に限る） | 必要 | 必要 |
| 住所の届出などの義務を果たしている | 必要 | 必要 |
| 本人を扶養している親などが身元保証人になり、日本に在留している | − | 必要 |

- ※留学など家族滞在以外の在留資格で在留していても、家族滞在の要件に当てはまる人は対象です。
- 高校などには、定時制・通信制の高校や高等専門学校も含まれます。
- 特定活動を希望する人が高校に途中から編入した場合は、卒業に加えてN2程度の日本語能力が必要です。日本語能力試験（JLPT）N2以上か、BJTビジネス日本語能力テスト400点以上の証明書を提出します。

申請は卒業見込みの段階でもできます。在学中に申請した人は、新しい在留カードを受け取るときに卒業証明書などを提出します。卒業してすぐ働けるよう、早めに準備しましょう。

### 定住者と特定活動の違い

定住者には、在留資格上の就労制限がありません。特定活動は、法務大臣が一人ひとりに指定する活動を行うための在留資格です。高校卒業者を対象としたこの特定活動では、指定された範囲内で働けます。次の営業に関わる仕事はできません。

- キャバクラなどの風俗営業
- 性風俗関連特殊営業
- 特定遊興飲食店営業

雇う前に、本人の指定書で働ける範囲を確認しましょう。

特定活動に変更した後も、次の要件をすべて満たせば、定住者への変更を目指せます。

- 日本の高校卒業以上の学歴がある
- 就労目的の特定活動か、就労できる在留資格（技能実習を除く）で5年以上在留している
- 就職先が決まっている（内定を含む）
- 自分の収入で生活を維持できる
- 入管法の届出などの義務を果たしている

日本の大学や専門学校など一定の学校で学んでから就職した場合は、学んだ期間を5年に含められることがあります。

## 特定技能1号・技人国に変更する場合

定住者や特定活動の要件を満たさない人も、ほかの在留資格への変更を検討できます。

**特定技能1号**：18歳以上であることなどが要件で、学歴は問われません。原則として、仕事の分野の技能試験と日本語能力試験に合格する必要があります。雇用契約と会社も基準を満たす必要があり、会社は[支援計画](../tokutei-ginou-support-plan/)を作って支援を行います。在留期間は原則として[通算5年以内](../tokutei-ginou-1-2-difference/)です。

[外食業分野](../tokutei-ginou-gaishoku/)では、受け入れる人数の上限に伴う制限があります。2026年4月13日以降に受け付けた家族滞在から外食業分野の特定技能1号への変更申請は、一部の例外を除き原則として不許可です（2026年11月10日付けの出入国在留管理庁の公表資料による）。

**技人国**：大学などで学んだ知識や一定の実務経験を生かして、専門的な仕事をする場合に検討できます。学歴や職歴、実際の仕事の内容、報酬などが要件を満たす必要があります。

育成就労と特定技能では、対象の分野や仕事の内容が違うことがあります。育成就労と特定技能1号では、本人の扶養を受ける配偶者や子どもが「家族滞在」の在留資格を取得することは、原則として認められていません。

## 本人の状況ごとの選択肢

| 本人の状況 | 検討できる在留資格 |
|---|---|
| 日本で義務教育を修了し、高校などを卒業した人 | 定住者 |
| 18歳未満で入国し、日本の高校などを卒業した人 | 特定活動 |
| 上の要件を満たさない18歳以上の人 | 特定技能1号、育成就労（変更の条件は未公表） |
| 大学などを卒業した人や、一定の実務経験がある人 | 技人国など |
| フルタイムで働きたい配偶者 | 技人国、特定技能1号、育成就労（変更の条件は未公表） |

どの場合も、それぞれの在留資格の要件を満たし、変更の許可を受ける必要があります。

大切なのは、フルタイムで雇う前に入国時の年齢や学歴、職歴を確認し、任せる仕事に合った在留資格を選ぶことです。<br>
遥か行政書士事務所は、在留資格の選択から申請書類の作成まで、在留資格の変更をサポートします。料金の目安は[こちら](../../#fees)をご覧ください。ご相談・ご依頼は、[お問い合わせフォーム](#article-contact)からお気軽にどうぞ。

## まとめ

- 家族滞在では原則として働けない。資格外活動許可（包括許可）があれば、許可の範囲で週28時間まで働ける
- 週28時間以内でも、扶養から外れて自分の収入で生活するようになると、家族滞在のままでいられなくなる可能性がある
- フルタイムで働くには在留資格の変更が必要で、許可を受けてから働き始める
- 育成就労へ変更できる可能性はあるが、家族滞在からの具体的な条件はまだ公表されていない
- 日本の高校などを卒業した人は、要件を満たせば定住者か特定活動に変更できる
- 特定技能1号や技人国への変更も、本人の経歴や仕事の内容に応じて検討できる

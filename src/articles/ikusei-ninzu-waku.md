2027年4月に始まる[育成就労](../ikusei-shuro/)では、会社が受け入れられる外国人の数に上限があります。これを「受け入れ人数枠」といいます。

人数枠は、会社の常勤職員の数によって決まります。「うちは何人まで受け入れられるのか」は、受け入れの計画を立てるうえで最初に確認したいことです。この記事では、人数枠の決まり方と、自社の人数枠の数え方を説明します。

## 人数枠は「常勤職員の数」で決まる

育成就労の人数枠は、受け入れる会社（育成就労実施者）の常勤職員の数に応じて決まります。[監理支援機関](../kanri-shien-kikan/)を通して受け入れる「監理型」の場合、基本の人数枠は次のとおりです。

| 常勤職員の数 | 基本の人数枠 |
|---|---|
| 1人 | 3人 |
| 2人 | 6人 |
| 3〜30人 | 9人 |
| 31〜40人 | 12人 |
| 41〜50人 | 15人 |
| 51〜100人 | 18人 |
| 101〜200人 | 30人 |
| 201〜300人 | 45人 |
| 301人以上 | 常勤職員の数の15％ |

この仕組みは、[技能実習](../ginou-jisshu-to-ikusei-shuro/)の人数枠を引き継いだものです。

## 1年目から3年目までの「合計」で数える

技能実習では、1号・2号・3号の段階ごとに人数枠が決まっていました。育成就労では段階の区分がなく、原則として**1年目から3年目までの外国人の合計**が人数枠を超えないようにします。やむを得ない事情で別の会社から移ってきた人など、人数枠に数えない例外もあります。

人数枠の範囲内であれば、同じ年度の中で、上限までまとめて受け入れることもできます。ただし、まとめて受け入れると、その人たちが育成就労を終えるまで、新しく受け入れられない期間が続くことになります。毎年少しずつ受け入れるか、まとめて受け入れるかは、育成の体制も考えて決めましょう。

## 優良と認められると、人数枠が広がる

受け入れの実績や体制などが評価され、「優良」と認められた会社は、人数枠が広がります。

| 区分 | 人数枠 |
|---|---|
| 一般の会社 | 基本の人数枠 |
| 優良な会社 | 基本の人数枠の2倍 |
| 地方にある優良な会社が、優良な監理支援機関の支援を受ける場合 | 基本の人数枠の3倍 |

ここでいう「地方」は、東京都・神奈川県・千葉県・埼玉県・愛知県・大阪府・京都府・兵庫県の8都府県以外の道県と、8都府県の中の一部の地域（指定区域）です。地方かどうかは、会社の本店の所在地で判断されます。外国人が大都市に集まりすぎないようにするための仕組みです。

なお、常勤職員が8人以下の会社は、2倍や3倍にしても、表の倍数どおりには増えません。たとえば常勤職員が5人の会社は、基本が9人、優良で15人、3倍の区分でも16人です。

## 常勤職員の数え方

人数枠を考えるときに、最も間違えやすいのが常勤職員の数え方です。

- **数えない人**：育成就労の外国人と、技能実習生
- **数える人**：日本人の常勤の社員のほか、[特定技能](../tokutei-ginou-1-2-difference/)など、ほかの[在留資格](../zairyu-shikaku-visa-difference/#zairyu-shikaku)で働いている常勤の外国人

日本人の社員が辞めて常勤職員の数が減ると、人数枠が小さくなり、新しく受け入れられる人数が減ることがあります。人数枠の境目に近い会社は、職員の数の変化にも気をつけましょう。

## 技能実習生も人数枠に含まれる？

2027年4月1日の時点で技能実習をしている人は、そのまま技能実習を続けられます。このうち、**技能実習1号・2号の人は、育成就労の外国人の数に含めて**人数枠を数えます。技能実習3号の人は、育成就労の人数枠には含めません（技能実習の制度での人数の制限は、引き続き受けます）。

技能実習1号・2号の人がまだ残っている会社は、その人数の分だけ、新しく受け入れられる育成就労の外国人が少なくなります。何号の実習生が何人いるかを確認してから計算しましょう。

## 自社の人数枠を数えてみる

たとえば、次のような会社で考えてみます。

- 常勤の日本人の社員：10人
- 特定技能の外国人：2人
- 技能実習2号の実習生：3人（2027年4月以降も実習を続ける）

常勤職員の数は、日本人10人と特定技能2人を合わせた**12人**です。技能実習生は数えません。12人は「3〜30人」の区分なので、基本の人数枠は**9人**です。

このうち3人分は技能実習2号の実習生で使っているので、新しく受け入れられる育成就労の外国人は、**あと6人**です。この会社が優良と認められれば、人数枠は18人になり、あと15人受け入れられます。

## そのほかに気をつけたいこと

1. **単独型は計算が違う**：海外の支店や子会社の職員を受け入れる「[単独型](../ikusei-tandoku-kanri/)」では、人数枠が常勤職員の数に対する割合で決まるなど、監理型とは計算の方法が違います
2. **分野ごとの上限もある**：介護の分野では、事業所ごとに、常勤の介護職員の数を超えて受け入れることはできません。分野によっては、このような上乗せの基準があります
3. **転籍で受け入れる人にも上限がある**：本人の希望で別の会社から移ってくる人（転籍者）を受け入れる場合は、原則として受け入れたあとの育成就労の外国人全体の3分の1までです。地方から大都市の会社に移る場合は、さらに厳しい上限があります

大切なのは、受け入れの計画を立てる前に、自社の常勤職員の数と人数枠を正しく確認しておくことです。遥か行政書士事務所は、人数枠の確認から、育成就労計画や在留資格の申請書類の作成・申請まで、手続きの面からサポートします。料金の目安は[こちら](../../#fees)をご覧ください。ご相談・ご依頼は、[お問い合わせフォーム](#article-contact)からお気軽にどうぞ。

## まとめ

- 育成就労で受け入れられる外国人の数には、常勤職員の数に応じた上限（人数枠）がある。常勤職員が3〜30人なら、基本の人数枠は9人
- 人数枠は、原則として1年目から3年目までの合計で数える
- 優良な会社は基本の2倍、地方にある優良な会社が優良な監理支援機関の支援を受ける場合は3倍まで広がる
- 常勤職員の数に、育成就労の外国人と技能実習生は含めない。特定技能など、ほかの在留資格の常勤の外国人は含める
- 2027年4月以降も残る技能実習1号・2号の実習生は、育成就労の外国人の数に含めて数える（3号は含めない）

2027年4月1日に[育成就労](../ikusei-shuro/)が始まると、技能実習の「監理団体」に代わって、「監理支援機関」が外国人と受け入れ企業の間に入るようになります。名前が「登録支援機関」と似ているため、混同されやすい機関でもあります。

この記事では、監理支援機関とはどんな機関か、監理団体や登録支援機関と何が違うのかを説明します。

## 制度ごとに関わる機関

外国人の受け入れには、似た名前の機関がいくつも出てきます。まず、どの[在留資格](../zairyu-shikaku-visa-difference/)にどの機関が関わるのかを整理しておきます。

| 在留資格 | 外国人と受け入れ企業を支える機関 | 計画の認定・監督など |
|---|---|---|
| 技能実習（2027年4月から育成就労に変わる） | 監理団体 | 外国人技能実習機構 |
| [育成就労](../ikusei-shuro/)（2027年4月から） | **監理支援機関** | 外国人育成就労機構 |
| [特定技能1号](../tokutei-ginou-1-2-difference/) | [登録支援機関](../registered-support-organization/)（支援を委託する場合） | 出入国在留管理庁 |
| [特定技能2号](../tokutei-ginou-1-2-difference/) | なし（支援は必要ない） | 出入国在留管理庁 |

この記事で説明する監理支援機関は、育成就労に関わる機関です。

## 監理支援機関とは

監理支援機関は、育成就労で、**外国人と受け入れ企業の雇用関係の成立をあっせんし、育成就労が適正に行われているかを監理・支援する機関**です。国の許可を受けた機関だけが、この事業を行えます。

育成就労では、受け入れ企業が海外の子会社や取引先の職員を受け入れる「単独型」を除き、監理支援機関を通して外国人を受け入れる「監理型」が一般的です。監理型で受け入れる場合、監理支援機関は欠かせない存在です。

## 監理支援機関の主な役割

出入国在留管理庁の資料では、監理支援機関の業務として、主に次のようなものが挙げられています。

- **雇用関係の成立のあっせん**：外国人と受け入れ企業を結びつける
- **送出機関との契約**：外国人の母国の送出機関（外国人の母国で、日本で働きたい人を集め、日本の受け入れ先につなぐ機関）と契約を結ぶ
- **育成就労計画の作成指導**：受け入れ企業が作る育成就労計画について指導する
- **入国後講習**：来日した外国人に、日本語や生活のルールなどの講習を行う
- **監査と訪問指導**：受け入れ企業を3か月に1回以上監査し、その報告書を外国人育成就労機構に提出する
- **外国人の保護・支援**：相談体制を整え、帰国までの生活を支える
- **転籍の連絡調整**：外国人が本人の意向で転籍（転職）を希望したときに、事実関係を確認し、ほかの受け入れ企業や監理支援機関などとの連絡調整を行う

最後の転籍の連絡調整は、技能実習にはなかった役割です。育成就労では、一定の条件を満たせば本人の意向で転籍できるようになるため、監理支援機関がその手続きの間に入ります。

## 監理団体から何が変わるのか

監理支援機関は、技能実習の監理団体の役割を引き継ぐ機関です。ただし、**今の監理団体がそのまま監理支援機関になれるわけではありません**。育成就労で監理支援機関として事業を行うには、新たに許可を受ける必要があります。

許可の基準は、監理団体より厳しくなります。主な点は次のとおりです。

| 項目 | 監理支援機関の許可の基準 |
|---|---|
| 監理支援機関になれる法人の種類 | 原則として、商工会議所、商工会、中小企業団体（事業協同組合など）、職業訓練法人、農業協同組合、漁業協同組合、公益社団法人・公益財団法人といった、営利を目的としない法人 |
| 外部監査人 | 外部監査人を置くこと。外部監査人は、所定の養成講習を受けた弁護士・社会保険労務士・行政書士などで、受け入れ企業と密接な関係がないことなどの要件を満たす必要がある |
| 監理する受け入れ企業の数 | 原則として2者以上（受け入れ企業には個人事業主も含まれるため、「社」ではなく「者」と数えます） |
| 監理支援の実務に従事する常勤の役職員の数 | 2人以上で、かつ、監理する受け入れ企業の数を8で割った数と、受け入れる外国人の数を40で割った数を、それぞれ上回っていること |
| 財産的基礎 | 監理支援機関自身が、債務超過でないこと |
| 監理支援責任者 | 監理支援事業を行う事業所ごとに、常勤の監理支援責任者を選任すること |

常勤の役職員の数は、たとえば、監理する受け入れ企業が16社、外国人が80人の場合、16÷8＝2、80÷40＝2で、どちらも「2」を上回る必要があるため、3人以上が必要になります。

### 受け入れ企業からの中立性が求められる

監理支援機関は、受け入れ企業を監査する立場にあります。そのため、育成就労では、受け入れ企業から独立して、中立に業務を行うことがより強く求められます。

たとえば、受け入れ企業の役員や職員（過去5年以内を含む）や、その配偶者・二親等以内の親族などは、その受け入れ企業についての監理支援の業務に、原則として関わることができません。外部監査人を置くことが許可の基準になったのも、外部の目で監理支援機関の業務をチェックするためです。

また、送出機関の役員が監理支援機関の役員を兼ねることはできず、送出機関からキックバックなどを受け取ることも禁止されています。

### 監理支援費のルール

監理支援機関は、受け入れ企業から「監理支援費」を受け取ることができます。監理支援費は、職業紹介費、講習費、監査指導費、その他諸経費に分かれていて、いずれも**実費に限られます**。受け取るときは、あらかじめ用途と金額を明らかにする必要があり、監理支援費のほかに手数料や報酬を受け取ることは認められていません。

また、受け入れ企業は、監理支援費を外国人本人に直接・間接に負担させてはいけません。

### 許可の有効期間

監理支援事業の許可の有効期間は、監理支援機関の能力や実績を勘案して、3年以上で設定されます。

## 監理支援機関と登録支援機関の違い

名前は似ていますが、監理支援機関と[登録支援機関](../registered-support-organization/)は、関わる制度も役割も違います。

| | 監理支援機関 | 登録支援機関 |
|---|---|---|
| 関わる制度 | 育成就労 | 特定技能1号 |
| 許可か登録か | 許可制 | 登録制 |
| 主な役割 | 雇用関係のあっせん、受け入れ企業への監査・指導、入国後講習、外国人の保護・支援、転籍の連絡調整 | 受け入れ企業から委託を受けて、[支援計画](../tokutei-ginou-support-plan/)にもとづく支援を行う |
| 受け入れ企業との関係 | 受け入れ企業を監査する立場 | 受け入れ企業から支援を任される立場 |
| 使うかどうか | 監理型で受け入れる場合は、監理支援機関を通す | 支援を自社で行うか、登録支援機関に委託するかを選べる |

いちばん大きな違いは、**受け入れ企業との関係**です。監理支援機関は受け入れ企業を監査し、指導する立場にあります。一方、登録支援機関は、受け入れ企業から支援を任される立場です。

### 同じ団体が両方を担うことはあるのか

監理支援機関の許可と登録支援機関の登録は、別々の制度です。同じ団体が育成就労と特定技能の両方の業務を行う場合は、監理支援機関としての許可と、登録支援機関としての登録を、それぞれ受け、それぞれの基準を満たす必要があります。

育成就労で育った外国人が特定技能1号に移ると、関わる機関も、監理支援機関から登録支援機関（または受け入れ企業自身による支援）に変わります。今お付き合いのある団体が、特定技能1号に移った後の支援まで担えるのかどうかは、早めに確認しておくと安心です。

## 監理支援機関を選ぶときに確認したいこと

育成就労の期間は、原則3年間です。受け入れ企業にとって、監理支援機関はその3年間を共に過ごすパートナーになります。選ぶときは、次のような点を確認しておくとよいでしょう。

1. **監理支援機関の許可を受けているか**：今の監理団体を使い続ける場合は、監理支援機関の許可を受ける予定か、すでに受けたかを確認する
2. **監理支援費の内訳が明らかか**：何にいくらかかるのか、用途と金額の説明を受ける
3. **体制が十分か**：担当者の人数、外国人の母国語での相談に対応できるか、入国後講習の内容
4. **転籍の希望が出たときの対応**：本人から転籍の希望が出た場合に、どのように対応するのか
5. **特定技能への移行後の支援**：特定技能1号に移った後の支援も任せられるのか、それとも別の登録支援機関を探す必要があるのか

## まとめ

- 監理支援機関は、育成就労で外国人と受け入れ企業の間に入り、あっせん、監査・指導、外国人の保護・支援を行う許可制の機関
- 技能実習の監理団体の役割を引き継ぐが、今の監理団体も新たに許可を受ける必要がある
- 外部監査人の設置や、受け入れ企業からの中立性など、許可の基準が厳しくなる
- 登録支援機関は特定技能1号の支援を行う登録制の機関で、関わる制度も役割も違う
- 監理支援機関を選ぶときは、許可、費用の内訳、体制、転籍への対応、特定技能への移行後の支援を確認する

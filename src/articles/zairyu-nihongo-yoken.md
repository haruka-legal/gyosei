外国人を雇うときに、「日本語はどれくらいできないといけないのか」と気になる会社は多いと思います。

実は、法令で求められる日本語の力は、[在留資格](../zairyu-shikaku-visa-difference/)によって大きく違います。日本語の試験がいらない在留資格もあれば、合格が条件になっている在留資格もあります。さらに、2027年4月からは、いくつかの在留資格で日本語の要件が見直されます。

この記事では、在留資格ごとの日本語の要件と、雇う会社が気をつけたいことを説明します。

## 日本語の力は「A1〜C2」の6段階で表す

在留資格の要件では、日本語の力を「**日本語教育の参照枠**」という基準で表すことが増えています。日本語教育の参照枠は、ヨーロッパの語学力の基準であるCEFR（Common European Framework of Reference for Languages、ヨーロッパ言語共通参照枠）をもとに、文化庁の審議会がまとめたもので、日本語の力を**A1からC2までの6段階**で表します。A1がもっとも初歩的で、C2がもっとも高いレベルです。

出入国在留管理庁の資料では、たとえば次の試験が、それぞれのレベルに当たるものとして挙げられています。

| レベル | 当たる試験の例 |
|---|---|
| A1相当 | 日本語能力試験（JLPT）N5 など |
| A2相当 | 日本語能力試験N4、国際交流基金日本語基礎テスト（JFT-Basic）など |
| B2相当 | 日本語能力試験N2、BJTビジネス日本語能力テスト400点以上 など |

日本語能力試験（Japanese-Language Proficiency Test、JLPT）は、N5からN1までの5段階で、N1がもっとも難しい試験です。

## ひと目でわかる、在留資格ごとの日本語の要件

| 在留資格 | 日本語の要件 |
|---|---|
| 技術・人文知識・国際業務（技人国） | 原則としてなし（翻訳・通訳など、主に言語の能力を使って人と接する仕事では、使う言語でB2相当） |
| 特定技能1号 | 日本語能力試験N4以上などに合格（技能実習2号を良好に修了した人は免除） |
| 特定技能2号 | 2027年4月1日以降の在留資格認定証明書の申請から、B1相当以上 |
| 育成就労 | 働き始める前にA1相当、特定技能1号に移るときにA2相当など、段階的に求められる |
| 特定活動（日本の大学などを卒業した人） | 日本語能力試験N1、またはBJT480点以上など |
| 経営・管理 | 申請者か常勤職員のいずれかがB2相当以上 |
| 永住者 | 2027年4月1日以降の申請から、B1相当以上かどうかが考慮される |

ここからは、それぞれの在留資格を見ていきます。

## 技人国は、原則として日本語の要件なし

[技人国](../gijinkoku/)（技術・人文知識・国際業務）には、法令上、日本語の試験に合格していることといった要件は、原則としてありません。日本語をほとんど話さないエンジニアが、英語で仕事をするケースもあります。

ただし、翻訳・通訳など、**主に言語の能力を使って人と接する仕事**をする場合は、その仕事で使う言語について、CEFRのB2相当の能力を持っていることが前提とされています。日本語を使う仕事であれば、日本語能力試験N2以上などが目安になります。

なお、B2相当の語学力があるからといって、それだけで仕事が技人国に当てはまるわけではありません。仕事の内容そのものが、技人国の対象になっている必要があります。

## 特定技能1号はN4程度、2号は2027年4月から変わる

### 特定技能1号

[特定技能](../tokutei-ginou-1-2-difference/)1号では、分野ごとの技能の試験に加えて、日本語の試験に合格する必要があります。多くの分野では、次のどちらかです。

- 国際交流基金日本語基礎テスト（JFT-Basic）で一定の水準以上
- 日本語能力試験（JLPT）N4以上

技能実習2号を良好に修了した人は、原則として職種を問わず、これらの日本語の試験が免除されます。

ただし、分野によっては上乗せの要件があります。たとえば介護では、上の試験に加えて「介護日本語評価試験」にも合格する必要があります（介護職種の技能実習2号を良好に修了した人は免除）。また、自動車運送業のバス・タクシーと、鉄道の運輸係員は、これまで日本語能力試験N3以上が求められていましたが、2027年4月1日以降の在留資格認定証明書の申請からは、B1相当以上に変わります。

### 特定技能2号

特定技能2号は、2027年4月1日以降の在留資格認定証明書の申請から、**分野を問わず、B1相当以上の日本語能力**が求められるようになります。

在留資格認定証明書は、海外から外国人を呼び寄せるときの申請です。日本にいる特定技能1号の人が2号に変わる場合（在留資格の変更）や、更新の場合の扱いは、2026年11月時点では「検討中」とされています。具体的な試験や点数も、今後案内される予定です。

## 育成就労は、段階的に日本語の力を伸ばす

2027年4月に始まる[育成就労](../ikusei-shuro/)では、日本語の要件が段階的に決められています。

| 時期 | 日本語の要件 |
|---|---|
| 働き始める前 | A1相当の試験（日本語能力試験N5など）に合格するか、A1相当の講習を受ける（試験に合格していない人は、認定日本語教育機関などで100時間以上） |
| 働き始めて1年がたつころ | 「1年目試験」として、A1相当の試験を受ける（不合格でも、育成就労は続けられる） |
| 育成就労の期間中 | A2相当の試験に合格していない人には、A2相当を目標とする100時間以上の講習を受けられるよう、会社が機会を用意する |
| 本人の意向で転籍するとき | 分野ごとに決められた水準の日本語の試験に合格している |
| 育成就労を終えるとき・特定技能1号に移るとき | A2相当の試験（日本語能力試験N4など）に合格している |

分野によっては、これより高い水準が決められることもあります。受け入れる会社には、外国人が日本語を学べる機会を確保することが求められます。

## 日本の大学を出た人の「特定活動」はN1が必要

日本の大学などを卒業した外国人が、日本語を使って幅広い仕事をするための在留資格として、「特定活動」（本邦大学等卒業者）があります。技人国では認められにくい、現場での仕事を含む業務にも就けるのが特徴です。

その分、日本語の要件は高く、**日本語能力試験N1か、BJTビジネス日本語能力テスト480点以上**が必要です。大学などで日本語を専攻して卒業した人は、この要件を満たすものとして扱われます。

また、仕事の内容にも条件があります。指示を受けて自分の作業をこなすだけでは足りず、通訳の要素がある仕事や、お客さんなどと双方向のやりとりが必要な仕事であることが求められます。

## 経営・管理は、申請者か常勤職員にB2相当

日本で会社を経営するための在留資格「[経営・管理](../keiei-kanri/)」では、2025年10月16日の改正で、日本語の要件が加わりました。**申請者本人か、常勤職員のいずれかが、B2相当以上の日本語能力**を持っている必要があります。日本語能力試験N2以上などが当たります。

## 永住許可でも、2027年4月から日本語が考慮される

永住許可のガイドラインが2026年10月1日に改定され、2027年4月1日以降の申請から、**B1相当以上の日本語能力を持っているか**が審査で考慮されることになりました。審査で考慮される要素の一つで、すべての申請者に日本語の試験の合格を一律に求めるものではありません。

ただし、次のような人は、この点を考慮しないとされています。

- 高度人材の外国人とその家族
- 日本の小学校・中学校などで、合わせて6年以上教育を受けた人
- 日本で生まれた永住者の子（親がB1相当以上の日本語能力を持っている場合に限る）など

## 雇う会社が気をつけたいこと

1. **在留資格の要件と、仕事に必要な日本語は別に考える**：技人国のように日本語の要件がない在留資格でも、社内の指示や安全のためのルールを理解できなければ、仕事は進みません。採用の前に、仕事で本当に必要な日本語の力を確認しておきましょう
2. **合格の証明書を確認する**：日本語の試験の合格は、申請のときに証明書で示します。本人の自己申告だけでなく、合格証明書などを確認しておくと安心です
3. **2027年4月の見直しに注意する**：特定技能2号や永住許可などでは、2027年4月から日本語の要件が厳しくなります。具体的な試験や点数は今後示されるものもあるので、申請の前に最新の案内を確認しましょう

大切なのは、在留資格で求められる日本語の水準と、仕事で実際に必要な日本語の力の両方を、雇う前に確認しておくことです。遥か行政書士事務所は、雇う人に合った在留資格の確認から、申請書類の作成・申請まで、手続きの面からサポートします。料金の目安は[料金のご案内](../../#fees)をご覧ください。[この記事の下のお問い合わせ](#article-contact)からお気軽にご相談ください。

## まとめ

- 在留資格で求められる日本語の力は、種類によって大きく違う
- 技人国には原則として日本語の要件はないが、言語の能力を使う仕事ではB2相当が前提になる
- 特定技能1号は日本語能力試験N4以上など、特定技能2号は2027年4月から在留資格認定証明書の申請でB1相当以上が求められる
- 育成就労では、働き始める前のA1相当から、特定技能1号に移るときのA2相当まで、段階的に日本語の力が求められる
- 日本の大学を卒業した人の特定活動はN1など、経営・管理は申請者か常勤職員にB2相当が必要
- 永住許可でも、2027年4月から日本語能力（B1相当以上）が考慮される

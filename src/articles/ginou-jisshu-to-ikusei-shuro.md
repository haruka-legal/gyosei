2027年4月1日、技能実習は[育成就労](../ikusei-shuro/)に変わります。30年以上続いた制度がなぜ見直されることになったのか、その流れを知っておくと、育成就労で何が変わるのか、なぜ変わるのかが分かりやすくなります。育成就労の制度の中身は、[育成就労とは？2027年4月に始まる新制度と、技能実習から変わること](../ikusei-shuro/)で詳しく説明しています。

この記事では、技能実習ができてから育成就労に変わるまでの流れを説明します。

## 年表で見る、技能実習から育成就労まで

| 時期 | 出来事 |
|---|---|
| 1993年 | 技能実習制度が始まる |
| 2010年7月 | 制度を改正し、在留資格「技能実習」を設ける |
| 2016年11月 | 技能実習法が成立・公布される |
| 2017年11月1日 | 技能実習法が施行される。監理団体の許可制や、外国人技能実習機構による監督などが始まる |
| 2019年4月 | 人手不足の分野で即戦力を受け入れる「特定技能」が始まる |
| 2020年6月 | アメリカ国務省の人身取引報告書で、日本の評価が引き下げられる。技能実習制度での強制労働の報告が続いていることなどが指摘される |
| 2022年12月14日 | 国の有識者会議（技能実習制度及び特定技能制度の在り方に関する有識者会議）が始まる |
| 2023年5月11日 | 有識者会議が中間報告書を出す |
| 2023年11月30日 | 有識者会議が最終報告書を出す |
| 2024年2月9日 | 政府が、最終報告書を踏まえた対応の方針を示す |
| 2024年6月14日 | 育成就労を作る改正法が成立する |
| 2024年6月21日 | 同じ改正法が公布される |
| 2025年10月1日 | 施行日を2027年4月1日とする政令が公布される |
| 2026年1月23日 | 分野ごとの運用方針が閣議決定される |
| 2027年4月1日 | 育成就労が始まる |

## 技能実習の目的は「国際貢献」だった

技能実習は、開発途上国などの人に日本で技能を身につけてもらい、母国に持ち帰って経済の発展に役立ててもらう、という**国際貢献**を目的とした制度です。そのため、制度の上では「労働力を確保するための制度ではない」とされてきました。

ところが実際には、人手不足に悩む中小企業などの現場で、重要な働き手として受け入れられてきました。技能を母国に移すという制度上の目的と、労働力の確保という実態とのずれが指摘されていたのです。

## 何が問題になっていたのか

目的と実態のずれは、外国人本人にとって深刻な問題につながっていました。

- **職場を変えられない**：技能実習は「決まった実習先で技能を学ぶ」制度なので、本人の希望で別の会社に移ること（転籍）は、原則として認められていませんでした。そのため、賃金の未払いや長時間労働などがあっても、職場から離れにくい状況がありました
- **来日前の借金**：母国の送出機関（外国人の母国で、日本で働きたい人を集め、日本の受け入れ先につなぐ機関）や仲介業者に高額な手数料を払うために、借金をして来日する人が少なくありませんでした。借金を返すために、劣悪な職場でも働き続けるしかない状況が生まれやすくなっていました
- **失踪や法令違反**：こうした状況から、実習先から姿を消す人や、受け入れ先での労働関係法令の違反も問題になっていました

## 国内外からの指摘

こうした問題は、国内だけでなく海外からも指摘されてきました。

アメリカ国務省は、毎年「人身取引報告書」で各国の取り組みを評価しています。2020年6月に発表された報告書では、日本の評価が4段階のいちばん上から1段階引き下げられました。その背景として、技能実習制度のもとで強制労働の報告が続いていたにもかかわらず、人身取引事件として特定・摘発されていなかったことや、送出機関による法外な手数料への対応が不十分なことが挙げられました。その後の報告書でも、技能実習制度の問題がくり返し取り上げられています。

## 有識者会議が「廃止して新しい制度へ」と提言

国は2022年12月、有識者会議を立ち上げ、技能実習と特定技能のあり方を見直す議論を始めました。

有識者会議は、2023年11月の最終報告書で、技能実習を廃止し、**人材の確保と人材の育成を目的とする新しい制度**を作るよう提言しました。国際貢献という建前を続けるのではなく、「日本の人手不足の分野で働く人を育て、確保する制度」として正面から位置づけ直す、という考え方です。

あわせて、本人の意向による転籍を一定の条件で認めること、送出機関に支払う費用を抑えること、監理団体の基準を厳しくすることなども示されました。

## 法律の成立から施行まで

政府は2024年2月にこの提言を踏まえた方針を示し、同年6月に、育成就労を作る改正法が公布されました。その後、2025年10月の政令で施行日が2027年4月1日と決まり、2026年1月には分野ごとの運用方針が閣議決定されています。

施行の前から準備も進んでいて、監理支援機関の許可申請や育成就労計画の認定申請は、すでに受け付けが始まっています。

## 育成就労で何が変わるのか

こうした流れを受けて、育成就労では主に次の点が変わります。

- **目的**：国際貢献から、人手不足の分野での人材の育成・確保へ
- **転籍**：一定の条件を満たせば、本人の意向で転籍できる
- **送出機関に支払う費用**：外国人が送出機関に支払う費用は、所定内賃金（残業代などを除いた月給）の2か月分を上限とする
- **監理する団体**：監理団体から、許可の基準が厳しい監理支援機関へ
- **その後の道**：3年間で特定技能1号の水準まで育て、特定技能1号に移ることを想定

それぞれの詳しい内容は、[育成就労とは？2027年4月に始まる新制度と、技能実習から変わること](../ikusei-shuro/)で説明しています。

## 受け入れる会社にとっての意味

技能実習から育成就労への変化は、「外国人を、国際貢献のために一時的に受け入れる」という考え方から、「日本で働き続けてもらう人材として育てる」という考え方への変化でもあります。

転籍が認められるようになる分、給与や職場環境、日本語や技能を身につけられる環境づくりが、そのまま人材の定着につながります。受け入れる会社にとっては、外国人に「この会社で働き続けたい」と思ってもらえるかどうかが、これまで以上に大切になります。

## まとめ

- 技能実習は1993年に、技能を母国に持ち帰ってもらう「国際貢献」を目的に始まった
- 実際には人手不足の現場の働き手として受け入れられることが多く、目的と実態がずれていた
- 転籍できないことや来日前の借金などが、人権上の問題として国内外から指摘された
- 国の有識者会議が2023年に、技能実習を廃止して新しい制度を作るよう提言した
- 2024年に法律が改正され、2027年4月1日から育成就労が始まる

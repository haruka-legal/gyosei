[特定技能1号](../tokutei-ginou-1-2-difference/)の外国人を受け入れるときに、在留資格の申請書類と一緒に作るのが「1号特定技能外国人支援計画」です。支援を[登録支援機関](../registered-support-organization/)に任せる場合でも、計画の中身は受け入れる会社の責任になります。

この記事では、支援計画で何を決めるのか、10項目の支援にはそれぞれどんな目安があるのかを説明します。

## 支援計画とは

1号特定技能外国人支援計画とは、受け入れる外国人が日本で安定して働き、暮らせるように、会社が行う支援の内容を定めた計画です。

- **対象**：[特定技能1号](../tokutei-ginou-1-2-difference/)の外国人です。2号の外国人には、支援計画は必要ありません
- **提出時期**：在留資格の申請時に同時に提出します。海外から呼ぶ場合は、来日前に会社が代理人となって行う在留資格認定証明書交付申請のとき、技能実習から移行するなど日本にいる人の場合は、在留資格変更許可申請のときです
- **言語**：日本語のほかに、外国人が十分に理解できる言語でも作成する必要があります。出入国在留管理庁は、支援計画書の[様式](https://www.moj.go.jp/isa/applications/ssw/10_00020.html)の英語版と9か国語版を公開しています
- **本人への説明と署名**：計画の写しを外国人に渡して内容を説明し、理解したうえで支援計画書に本人の署名をもらいます

## 義務的支援の10項目

支援計画には、出入国在留管理庁が定める次の10項目の「義務的支援」を書き、そのとおりに実施する必要があります。下記表の「目安」項目に書かれている時間や面積などは、出入国在留管理庁の[運用要領](https://www.moj.go.jp/isa/content/930004553.pdf)に示された原則や実施の目安であり、実際は外国人本人の状況や支援の内容に応じた対応が必要です。

| 支援 | 主な内容 | 目安 |
|---|---|---|
| 1. 事前ガイダンス | 雇用契約を結んだあと、在留資格の申請前に、契約の内容や日本での仕事・生活について説明する | 3時間程度。対面かテレビ電話などで行い、郵送やメールだけでは不可 |
| 2. 出入国する際の送迎 | 入国時は空港などから事業所・住居まで送る。帰国時は空港の保安検査場の前まで同行する | ― |
| 3. 住居確保・生活に必要な契約支援 | 住居探しや連帯保証人の確保、銀行口座・携帯電話・電気ガス水道などの手続きを手伝う | 居室は原則として1人あたり7.5㎡以上（技能実習からの移行など一定の例外あり） |
| 4. 生活オリエンテーション | 日本の生活ルールや交通、医療、災害時の対応などを説明する | 8時間以上 |
| 5. 公的手続等への同行 | 住民登録や社会保険、税などの手続きについて、必要に応じて窓口に同行し、本人による書類の記入などを補助する | ― |
| 6. 日本語学習の機会の提供 | 日本語教室の案内や、教材・オンライン講座の情報提供などを行う | ― |
| 7. 相談・苦情への対応 | 仕事や生活の相談に、外国人が理解できる言語で応じる | 勤務日は週3日以上、休日も1日以上対応できる体制 |
| 8. 日本人との交流促進 | 地域の行事や交流の場を案内し、参加を手伝う | ― |
| 9. 転職支援（人員整理等の場合） | 会社の都合で雇用契約を終了する場合に、次の仕事探しを手伝う | ― |
| 10. 定期的な面談・行政機関への通報 | 外国人本人と、その監督者のそれぞれと面談する。法令違反などがあれば行政機関に通報する | 3か月に1回以上 |

生活オリエンテーションの「8時間以上」や、定期面談の「3か月に1回以上」は、実際に受け入れてから負担を感じやすい部分です。自社で支援するかどうかを決める前に、社内で誰がいつ対応するのかを具体的に考えておくことが大切です。

## 任意的支援は「書いたら義務」になる

10項目のほかに、会社が自主的に行うことが望ましい「任意的支援」もあります。たとえば、渡航費や入国後の当面の生活費の貸付け、日本語教室の入学金や月謝の負担、日本語の試験の受験の支援、相談・苦情専用の電話番号やメールアドレスの設置などです。

注意したいのは、任意的支援であっても、**支援計画に書いた場合は実施する義務が生じる**ことです。できるかどうか分からない支援は、計画に書かないほうが安全です。

## 支援の費用は外国人に負担させない

義務的支援にかかる費用は、直接にも間接にも、外国人本人に負担させることはできません。登録支援機関に委託する場合の委託料も、会社が負担します。

## 自社で支援するための基準

上記の義務的支援10項目のほかに、次の基準をすべて満たす必要があります（特定技能基準省令第2条第2項）。

1. **実績・経験と担当者の選任**：次のどれかにあてはまり、役員・職員の中から、支援責任者と、外国人が働く事業所ごとに1人以上の支援担当者を選んでいること（支援責任者は支援担当者を兼ねられる）
   - 過去2年間に、働くことが認められた在留資格で日本にいる中長期在留者の受け入れや管理を、適正に行った実績がある
   - 過去2年間に、そうした中長期在留者の生活相談業務に従事した経験のある役員・職員がいて、その中から選んでいる
   - これらと同程度に、支援業務を適正に実施できると認められる人の中から選んでいる
2. **言語**：外国人が十分に理解できる言語で支援できる体制があること
3. **記録の保管**：支援の状況についての文書を作り、雇用契約が終わった日から1年以上、支援を行う事業所に保管すること
4. **中立性**：支援責任者と支援担当者が、外国人を監督する立場にないなど、中立に支援できる立場の人であり、法令で定める欠格事由にもあたらないこと
5. **過去に支援を怠っていないこと**：雇用契約を結ぶ前の5年以内や契約後に、支援計画に基づく支援を怠ったことがないこと
6. **定期面談の体制**：支援責任者か支援担当者が、外国人とその監督者のそれぞれと定期的に面談できる体制があること
7. **分野ごとの基準**：分野によっては、その分野を所管する省庁が定める上乗せの基準も満たすこと

これらの基準を満たせない場合は、支援計画の全部を登録支援機関に委託することで、支援体制の基準を満たしているものとみなされます。委託の仕組みについては、[登録支援機関とは？特定技能の支援を自社で行う場合との違い](../registered-support-organization/)で説明しています。

## 支援の実施状況は年に1回届け出る

会社は、外国人の受け入れ状況や活動状況、支援計画に基づく支援の実施状況について、年に1回、出入国在留管理庁に届け出る必要があります。2025年（令和7年）からは、四半期ごとの届出から、年に1回「受入れ・活動・支援実施状況に係る届出」を提出する方法に変わりました。

対象期間は毎年4月1日から翌年3月31日までの1年度で、翌年度の4月1日から5月31日までに提出します。登録支援機関に支援の全部を委託している場合も、提出するのは受け入れる会社です。届出書のうち支援の実施状況の部分は、会社が登録支援機関と情報を共有して作成し、登録支援機関も作成者として届出書に記載します。

届出の内容に合わせて、面談の記録や、オリエンテーションの確認書などを残しておくことが大切です。また、支援計画の内容を変更したときは、軽微な変更を除き、変更の事由が生じた日から14日以内に届出が必要です。

## 2027年4月から、支援体制の基準が変わる

出入国在留管理庁は、2027年（令和9年）4月1日から、1号特定技能外国人への支援体制の要件を改正すると公表しています。登録支援機関だけでなく、自社で支援する会社にも、事業所ごとの支援責任者・支援担当者の配置などの新しい要件が適用されます。

- 支援を行う事業所ごとに、常勤の役員または職員から、支援責任者と支援担当者をそれぞれ1人以上選ぶ
- 支援業務に従事できるのは、支援責任者と支援担当者に限られる
- 支援責任者には、入管法や労働関係法令などを学ぶ養成講習の修了が義務付けられる。自社で支援する会社では会社の支援責任者が、登録支援機関に委託する場合は登録支援機関の支援責任者が対象。講習は法務大臣が告示した養成講習機関が行う（ただし、経過措置により、当分の間はこの修了義務は適用されない）
- 登録支援機関には、受託する会社の数と支援する外国人の数に応じて、必要な支援担当者の人数の基準ができる

今は自社で支援している会社も、2027年4月以降も同じ体制で続けられるか、早めに確認しておくと安心です。

## 支援計画を作るときに気をつけたいこと

1. **実際にできる内容だけを書くこと**：書いた支援は義務になる。特に任意的支援は慎重に
2. **担当者と日程を決めておくこと**：生活オリエンテーションや3か月ごとの面談を、誰がいつ行うのか決めておく
3. **外国人が理解できる言語を確認すること**：計画の作成や相談対応を、どの言語で行うのか決めておく
4. **記録を残すこと**：年1回の届出に備えて、支援の実施記録を残しておく

## まとめ

- 特定技能1号の外国人を受け入れる会社は、支援計画を作り、在留資格の申請のときに提出する
- 支援計画には10項目の義務的支援を書き、そのとおりに実施する。生活オリエンテーションは8時間以上、定期面談は3か月に1回以上が目安
- 任意的支援も、計画に書いたら義務になる
- 支援の費用は外国人本人に負担させない
- 自社で支援するには、受け入れ実績や生活相談の経験などに加え、言語対応・記録の保管・中立性など、法令で定められた基準を満たす必要がある。満たせない場合は登録支援機関に全部を委託できる
- 支援の実施状況は、年に1回（4月1日〜5月31日）届け出る。全部委託していても届け出るのは会社
- 2027年4月から、自社で支援する会社にも新しい基準が適用される

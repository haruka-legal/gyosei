ソープランドや店舗型ヘルス、デリヘルなどを経営していると、警察官がお店や事務所に来て、営業の様子や書類を確かめていくことがあります。風営法にもとづく「立入検査」です。

この記事では、性風俗店への立入検査で確認されることと、普段から準備しておきたいことを説明します。[スナックやバーへの立入検査](../police-inspection-snack-bar/)とは、確認される項目が少し違います。

## 立入りの対象になる場所

風営法では、警察職員が、法律の施行に必要な範囲で、次のような場所に立ち入ることができるとしています（風営法37条2項）。

- ソープランド、店舗型ヘルス、ストリップ劇場、ラブホテル、アダルトショップなど、店舗型の性風俗店の営業所
- デリヘル（派遣型ファッションヘルス）などの事務所、受付所、待機所

届出をしたお店に限らず、届出をせずに営業しているお店も対象です。

ただし、店舗型の性風俗店の個室などで、お客様が中にいる部屋は、立入りの対象から外されています（37条2項ただし書）。警察庁の解釈運用基準でも、個室に入る場合はノックするなどして、お客様がいないことを確かめるとされています。

## 立入検査は犯罪捜査ではない

立入検査は、風営法の決まりが守られているかを確かめるための行政の手続きです。法律で、犯罪捜査のために認められたものと解釈してはならないと定められています（37条4項）。

立ち入る警察官は、身分を示す証明書を持ち、関係者に見せることになっています。質問は原則としてお店の側の人に対して行われ、営業時間中は、できるだけ営業の妨げにならないように行うとされています。

ただし、立入検査の中で違反が見つかれば、指導や行政処分につながることがあります。売春など犯罪の疑いがあれば、別に捜査が行われることもあります（[夜のお店が摘発される理由](../why-night-businesses-get-raided/)）。

## 立入検査で確認される可能性がある項目

| 項目 | 確認されること |
| --- | --- |
| 届出の内容 | 届出をしているか。届け出た営業の種類、営業所の造り、営業時間などと、実際の営業が合っているか |
| 届出確認書 | 届出のあとに受け取った届出確認書を、店舗型なら営業所に、デリヘルなどの無店舗型なら事務所に備えているか |
| 従業者名簿 | 店舗型なら営業所ごとに、無店舗型なら事務所に、従業者名簿を備えているか |
| 年齢・在留資格の確認記録 | お客様に接する仕事をさせる前に、生年月日や国籍、外国籍の人の在留資格などを決められた書類で確かめ、その記録を作って保存しているか |
| 18歳未満の扱い | 営業の種類に応じて決められた、18歳未満の利用や、18歳未満を働かせることについての禁止を守っているか |
| 18歳未満の表示 | 店舗型のお店で、入口に18歳未満が入れないことを示す表示をしているか。広告や宣伝で、18歳未満が入れないことを明らかにしているか |
| 広告・客引き | 決まりに反する広告や、客引きをしていないか |
| 営業時間・場所 | 条例で決められた時間や、営業できる場所の決まりを守っているか |

## すぐ出せるようにしておくもの

- 届出確認書
- 従業者名簿
- お客様に接する従業員の年齢・国籍・在留資格を確かめた記録
- 届出のときに出した営業所の平面図など、届出の内容がわかる書類の控え

従業者名簿と年齢などの確認記録は、従業員が辞めたあとも、原則として3年間保存します。確認記録は、確認に使った書類の写しなどとあわせて保存する決まりです。

必要な書類をきちんと備え付け、立入検査のときに確認できるよう、保管場所を決めておきましょう。店長など現場の責任者もすぐ出せるようにしておくと安心です。

## 立入りを断ったらどうなる？

正当な理由なく立入りを拒んだり、妨げたり、逃れたりすると、100万円以下の罰金の対象になります。

立入りに来た警察官には、まず身分証明書を見せてもらい、落ち着いて対応しましょう。経営者がその場にいない場合に備えて、現場のスタッフに対応のしかたを決めておくことも大切です。

## 普段からしておくこと

- 店内の造りや営業の内容を変えるときは、変更の届出が必要かを前もって確かめる
- 従業員が入ったり辞めたりしたら名簿を更新し、確認記録とあわせて保存しておく
- 採用のときに、身分証で年齢と在留資格を確かめる。留学生などのアルバイトは、性風俗の仕事では働けません（[外国籍スタッフを雇うときの決まり](../foreign-staff-night-business/)）
- 広告の内容や、客引きをしていないかを見直す

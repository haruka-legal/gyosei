外国籍の方から、日本で自分のスナックやバーを開きたいというご相談があります。外国人がお店を経営するときは、お店の許可や届出のほかに、日本で経営をしてよい在留資格を持っているかが問題になります。

この記事では、外国籍の方がスナック・バー・キャバクラなど夜のお店を経営するときに必要な、在留資格と風営法の手続きを説明します。

## 経営できる在留資格・できない在留資格

日本で事業を経営できるかどうかは、持っている在留資格で決まります。

| 在留資格 | お店の経営 |
| --- | --- |
| 永住者・日本人の配偶者等・永住者の配偶者等・定住者 | 在留資格による活動の制限なし |
| 経営・管理 | 認められた範囲で経営・管理ができる |
| 留学・家族滞在 | 原則としてできない。資格外活動許可の対象になる活動もあるが、風俗営業のお店などでの活動は認められない |
| 技術・人文知識・国際業務、特定技能など働くための在留資格 | 原則としてできない。資格外活動許可などの例外は個別に判断され、風俗営業のお店などでの活動は認められない |

永住者や日本人の配偶者などの在留資格は、日本での活動に制限がありません。お店の許可や届出を受ければ、日本人と同じように経営できます。

一方、留学生や、会社員として働くための在留資格の方は、そのままではお店を経営できません。経営を始めるには、在留資格「経営・管理」への変更などが必要です。

なお、会社の株を持つことと、実際に事業を経営することは別です。株主になるだけなら在留資格の問題になりにくい一方、自分でお店を切り盛りすれば経営の活動に当たります。

## 「経営・管理」の条件が2025年10月に厳しくなった

在留資格「経営・管理」は、日本で事業を経営したり管理したりする外国人のための在留資格です。2025年10月16日から、許可の条件が大きく変わりました。

| 条件 | 内容 |
| --- | --- |
| 資本金など | 資本金等3,000万円以上（以前は500万円以上）。個人事業の場合は、事業に投下した総額 |
| 常勤職員 | 1人以上を雇う（日本人、特別永住者、永住者・日本人の配偶者等・永住者の配偶者等・定住者に限る） |
| 日本語能力 | 申請する本人か常勤職員が、一定の日本語能力を持つ |
| 経歴・学歴 | 経営・管理または経営する事業分野に関する修士相当以上の学位、または経営・管理に関する3年以上の実務経験 |
| 事業計画書 | 中小企業診断士・公認会計士・税理士に、具体性や実現の見込みを確かめてもらう |
| 事業所 | 事業の規模に合った事業所を確保する（自宅を事業所にすることは原則として認められない） |

日本語能力は、ヨーロッパ言語共通参照枠（CEFR）のB2程度が目安とされています。外国籍の方の場合、日本語能力試験（JLPT）N2以上、BJTビジネス日本語能力テスト400点以上、日本の大学などの卒業などで確かめます。

資本金3,000万円は、スナックやバーのような小さなお店を一人で始める方には高いハードルです。お店の規模に対して条件が重くなったため、外国籍の方が新しく経営・管理の在留資格を取ってお店を開くのは、以前よりかなり難しくなりました。

### すでに経営・管理で在留している方

改正前から経営・管理の在留資格で事業をしている方は、施行日から3年を経過する日（2028年10月16日）までの更新では、新しい条件を満たしていないことだけを理由に不許可にはならないとされています。経営の状況や、新しい条件を満たす見込みなどを踏まえて判断されます。ただし、税金や社会保険の支払い、必要な営業許可などに問題があれば、更新が認められないことがあります。

それ以降の更新では、原則として新しい条件を満たす必要があります。早めに準備を始めることが大切です。

## 風俗営業の許可に国籍の条件はない

接待をするスナックやキャバクラを開くには、風営法の風俗営業の許可が必要です。この許可には、国籍の条件はありません。外国籍の方でも、許可の条件（欠格事由に当たらないこと、営業所の場所や構造など）を満たせば許可を受けられます。

申請のときは、日本人と同じように住民票の写しを出します。外国籍の方の場合は、本籍の代わりに国籍などが書かれた住民票の写しになります。

接待をせず深夜0時以降にお酒を出すバーなら、[深夜酒類提供飲食店営業の届出](../late-night-liquor-notification-tokyo/)をします。こちらも国籍の条件はありません。どちらの手続きになるかは自由に選べるものではなく、接待をするかどうか、営業時間、営業の中身で決まります。

ただし、許可や届出に国籍の条件がないことと、その在留資格で経営できることは別の問題です。在留資格の確認とお店の手続きは、両方そろえる必要があります。

## 気をつけたいこと

- **経営者自身が接客や調理をする場合**：在留資格「経営・管理」は、事業の経営や管理をするための在留資格です。経営者自身が接客や調理などの現場の仕事を主にしていて、実際には経営や管理をしていない場合、在留資格で認められた活動に当たらないと判断されるおそれがあります。現場の仕事を一切してはいけない、という意味ではありません
- **外国籍のスタッフを雇う場合**：働ける仕事の範囲は、[スタッフ本人の在留資格](../foreign-staff-night-business/)によって違います。永住者や日本人の配偶者等など、就労の制限がない在留資格の方は、接待をする仕事にも就けます。一方、留学生などは、資格外活動許可を受けていても、風俗営業のお店で働くことは認められません。接待をしない一般的なバーでは、営業の形と在留資格に応じて個別に判断します
- **他人の名義で営業する場合**：実際に営業する人とは違う人の名義で風俗営業の許可を受けることは、名義貸しなどの問題につながります。また、外国籍の方が在留資格で認められていない経営の活動をすれば、入管法違反になるおそれがあります

## 手続きの順番の例

1. 物件を探し、営業できる場所かどうかを確かめる（用途地域・学校などとの距離）
2. 経営・管理の在留資格が必要なら、会社の設立や資本金の準備、常勤職員の確保、事業計画書の作成を進める
3. 在留資格の申請（海外から来る場合は在留資格認定証明書の交付申請）
4. 保健所の飲食店営業許可
5. 風俗営業の許可申請、または深夜酒類提供飲食店営業の届出

実際の順番は、在留の状況やお店の営業の形によって変わります。経営・管理の申請には事業所の確保が必要で、風俗営業の許可にも営業所が必要です。どちらの手続きも物件が前提になるため、物件の契約の前に、在留資格とお店の許可の両方の見通しを立てておくことが大切です。

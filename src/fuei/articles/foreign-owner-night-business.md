外国籍の方から、日本で自分のスナックやバーを開きたいというご相談があります。外国人がお店を経営するときは、お店の許可や届出のほかに、日本で経営活動が認められる在留資格を持っているかが問題になります。

この記事では、外国籍の方がスナック・バー・キャバクラなど夜のお店を経営するときに必要な、在留資格と風営法の手続きを説明します。

## 経営できる在留資格・できない在留資格

日本で事業を経営できるかどうかは、持っている在留資格で決まります。

| 在留資格 | お店の経営 |
| --- | --- |
| 永住者・日本人の配偶者等・永住者の配偶者等・定住者 | 在留資格による活動の制限なし |
| 経営・管理 | 在留資格で認められる範囲で経営・管理ができる |
| 留学・家族滞在 | 原則としてできない。資格外活動許可を受けられる活動もあるが、風俗営業などの営業所での活動は許可の対象外 |
| 技術・人文知識・国際業務 | 原則としてできない。資格外活動許可を受けられるかは個別に判断される |
| 特定技能 | 原則としてできない。一般的な資格外活動許可で、別の事業を経営することはできない |

永住者や日本人の配偶者などの在留資格は、日本での活動に制限がありません。お店の許可や届出を受ければ、日本人と同じように経営できます。

一方、留学生や、会社員として働くための在留資格の方は、そのままではお店を経営できません。経営を始めるには、在留資格「経営・管理」への変更などが必要です。

表の「できない」は、その在留資格では経営の活動が認められない、という意味です。

なお、会社の株を持つことと、日本で実際に経営の活動をすることは別です。在留資格の判断では、肩書きだけでなく、本人が実際にどのような活動をしているかが重視されます。

## 「経営・管理」の条件が2025年10月に厳しくなった

在留資格「経営・管理」は、日本で事業を経営したり管理したりする外国人のための在留資格です。2025年10月16日に、在留資格「経営・管理」の許可基準が改正されました。

| 条件 | 内容 |
| --- | --- |
| 資本金など | 資本金等3,000万円以上。法人は資本金や出資の総額、個人事業は事業所の確保費用・職員の給与1年分・設備投資など、事業のために投下されている額で判断（改正前は500万円以上の事業規模などが基準） |
| 常勤職員 | 1人以上を雇う（日本人、特別永住者、永住者・日本人の配偶者等・永住者の配偶者等・定住者に限る） |
| 日本語能力 | 申請する本人か、日本に住む常勤職員のどちらかが、一定の日本語能力を持つ（この常勤職員は、上の雇用の条件に数えられない外国籍の職員でもよい） |
| 経歴・学歴 | 経営・管理または経営する事業分野に関する修士相当以上の学位、または経営・管理に関する3年以上の実務経験 |
| 事業計画書 | 中小企業診断士・公認会計士・税理士など、入管庁が認める専門家に、具体性や実現の見込みを確かめてもらう |
| 事業所 | 事業の規模に合った事業所を確保する（自宅を事業所にすることは原則として認められない） |

日本語能力は、「日本語教育の参照枠」のB2相当以上が求められます。外国籍の方の場合、日本語能力試験（JLPT）N2以上、BJTビジネス日本語能力テスト400点以上、日本の大学などの卒業などで確かめます。

資本金等3,000万円は、スナックやバーのような小さなお店を一人で始める方には高いハードルです。お店の規模に対して条件が重くなったため、外国籍の方が新しく経営・管理の在留資格を取ってお店を開くのは、以前よりかなり難しくなりました。

### すでに経営・管理で在留している方

改正前から経営・管理の在留資格で事業をしている方は、施行日から3年を経過する日（2028年10月16日）までの更新では、新しい条件を満たしていないことだけを理由に不許可にはならないとされています。経営の状況や、新しい条件を満たす見込みなどを踏まえて判断されます。ただし、税金や社会保険の支払い、必要な営業許可などに問題があれば、更新が認められないことがあります。

2028年10月16日以降の更新では、原則として新しい条件を満たす必要があります。ただし、条件を満たしていなくても、経営の状況が良好で、納税の義務をきちんと果たし、次の更新までに新しい条件を満たす見込みがある場合などは、在留の状況を総合的に判断して許可される可能性があります。早めに準備を始めることが大切です。

## 風俗営業の許可に国籍の条件はない

接待をするスナックやキャバクラを開くには、風営法の風俗営業の許可が必要です。この許可には、国籍の条件はありません。外国籍の方でも、許可の条件（欠格事由に当たらないこと、営業所の場所や構造など）を満たせば許可を受けられます。

個人で申請する場合は、申請者の住民票の写しなどを出します。外国籍の方は、本籍の代わりに国籍が書かれた住民票の写しが必要です。法人の場合は、役員についても必要な書類が決められています。

接待をせず、深夜0時から朝6時までの時間帯にお酒を出すことを営業の常態とするバーなどは、原則として[深夜酒類提供飲食店営業の届出](../late-night-liquor-notification-tokyo/)が必要です。こちらも国籍の条件はありません。ただし、通常主食と認められる食事を出すことが営業の常態になっている飲食店は対象外です。また、深夜にお客様を積極的に遊興させる場合は、特定遊興飲食店営業の許可が必要になることがあります。どちらの手続きになるかは自由に選べるものではなく、接待をするかどうか、営業時間、営業の中身で決まります。

ただし、許可や届出に国籍の条件がないことと、その在留資格で経営できることは別の問題です。在留資格の確認とお店の手続きは、両方そろえる必要があります。

## 気をつけたいこと

- **経営者自身が接客や調理をする場合**：在留資格「経営・管理」は、事業の経営や管理をするための在留資格です。経営者自身が接客や調理などの現場の仕事を主にしていて、実際には経営や管理をしていない場合、在留資格で認められた活動に当たらないと判断されるおそれがあります。現場の仕事を一切してはいけない、という意味ではありません
- **外国籍のスタッフを雇う場合**：働ける仕事の範囲は、[スタッフ本人の在留資格](../foreign-staff-night-business/)によって違います。永住者や日本人の配偶者等など、就労の制限がない在留資格の方は、接待をする仕事にも就けます。一方、留学生などは、資格外活動許可を受けていても、風俗営業が営まれる営業所で働くことは認められません。接待だけでなく、調理や清掃などの仕事も同じです。接待をしない一般的なバーでは、営業の形と在留資格に応じて個別に判断します
- **他人の名義で営業する場合**：実際に営業する人とは違う人の名義で風俗営業の許可を受けることは、名義貸しなどの問題につながります。また、外国籍の方が在留資格で認められていない経営の活動をすれば、入管法違反になるおそれがあります

## 手続きの進め方

まず、今の在留資格で経営できるか、新しく「経営・管理」を取る必要があるかを確かめます。同時に、予定しているお店の営業の中身に合わせて、物件の用途地域や風営法の場所の決まりなどを調べます。

「経営・管理」を取る必要がある場合は、会社の設立、資本金等の準備、常勤職員の雇用、事業所の確保、事業計画書の作成などを進めます。

経営・管理の審査では、飲食店営業の許可や風俗営業の許可など、事業に必要な許認可を取っているかも確かめられます。在留資格の許可を受けたあとでないと営業の許可を取れないなど、正当な理由がある場合は、次の更新のときに資料を出す扱いも示されています。

実際の申請の順番は、今の在留資格、海外から来日するかどうか、お店の営業の形、必要な許認可によって変わります。物件の契約や大きなお金を使う前に、入管と警察の両方の手続きの見通しを立てておくことが大切です。

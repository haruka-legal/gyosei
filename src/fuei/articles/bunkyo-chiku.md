物件を探していて、不動産会社の資料に「第二種文教地区」と書かれていた。そんなとき、そこでスナックやバーを開けるのか迷う方は多いと思います。

この記事では東京都の文教地区でどのようなお店を開けるのかを、東京都文教地区建築条例の条文にそって説明します。

## 文教地区とは

文教地区とは学校や図書館、博物館などが集まる地域の教育環境を守るために、都市計画で指定される地区です。法律では「特別用途地区」の一つで、用途地域の上に重ねて指定されます。

東京都では文教地区の中で建てたり使ったりできる建物の用途を、東京都文教地区建築条例で決めています。文教地区は制限の強さによって第一種文教地区と第二種文教地区に分かれます（条例2条）。

たとえば千代田区では番町・富士見・神保町の一部、台東区では上野公園のまわりの一部などに文教地区が指定されています。区によって指定の場所は違います。

## 第一種・第二種で制限される建物

文教地区の中では次の用途のために建物を建てたり、建物の用途を変えたりすることが禁止されています（条例3条・4条、別表一・別表二）。

| 用途 | 第一種文教地区 | 第二種文教地区 |
| --- | --- | --- |
| 接待をするスナック・キャバクラ・ラウンジなど（風俗営業1号） | 制限 | 制限 |
| 低照度飲食店・区画席飲食店（風俗営業2号・3号） | 制限 | 制限 |
| ソープランド・店舗型ヘルス・ラブホテル・アダルトショップなどの店舗型性風俗 | 制限 | 制限 |
| ホテル・旅館 | 制限 | 制限 |
| 劇場・演芸場・観覧場、ナイトクラブなど客にダンスをさせて飲食させる施設 | 制限 | 制限 |
| 映画館 | 制限 | この条例の別表では制限対象外 |
| 遊技場（パチンコ店・ゲームセンターなど） | 制限 | この条例の別表では制限対象外 |
| マーケット（市場を除く） | 制限 | この条例の別表では制限対象外 |
| 一定の工場（旧工場公害防止条例に掲げられていた作業を常に行うもの） | 制限 | この条例の別表では制限対象外 |
| 勝馬投票券発売所・場外車券売場など | 制限 | 制限 |
| 上の建物に類し、環境を害し、または風俗を乱すおそれがあると認めて知事が指定する建物（一定の飲食店） | 制限 | 制限 |

第一種のほうが制限が広く、第二種は映画館や遊技場などがこの条例の別表から外れています（用途地域などによる制限は別にあります）。ただ、接待をするスナックやキャバクラは、第一種でも第二種でも制限の対象です。

ただし、知事が文教上必要と認めた場合や、文教上の目的を害するおそれがないと認めて許可した場合には、例外として建築や用途変更が認められることがあります（条例3条・4条ただし書）。この例外の許可を受けても、風営法の許可を受けられるとは限りません。

## 空き店舗を借りて開く場合も対象

この条例は建物を新しく建てるときだけでなく、建物の「用途を変更」するときにも適用されます。

そのため、文教地区にある事務所や一般の飲食店を借りて、接待をするスナックとして使うことも、原則として認められません。建築確認の申請が必要かどうかとは別に、実際にどのような用途で建物を使うかが問題になります。ビルがすでに建っているから自由に営業できる、ということにはなりません。

違反した場合は建築主・所有者・管理者・占有者が20万円以下の罰金の対象となります（条例5条）。建物を借りて営業する人も、占有者として対象になる可能性があります。法人の業務に関して違反があった場合は、法人も罰金の対象になることがあります（条例6条）。

## 接待をしないバーは開ける？

接待や深夜の遊興をしない一般的なバーは、低照度飲食店などに当たる場合を除き、通常は風俗営業に当たりません。ただ、それだけで文教地区でも開けるとは言い切れません。

条例の別表には第一種・第二種ともに「環境を害し、又は風俗を乱すおそれがあると認めて知事が指定するもの」という項目があります。東京都の告示（昭和42年東京都告示第916号）では次の飲食店がこれに指定されています。都内のすべての文教地区に共通する決まりです。

- 共同住宅（マンションなど）の、主に住戸や住室がある階に設ける飲食店
- それ以外の飲食店で、第一種・第二種低層住居専用地域、第一種・第二種中高層住居専用地域、田園住居地域に設けるもの

ただし、第二種中高層住居専用地域では、お酒を出す飲食店のうち、通常主食と認められる食事を出すことが営業の中心ではないものに限られます。

つまり、文教地区の中でもマンションの住戸がある階や住居専用地域では、接待をしないバーや居酒屋も開けないことがあります。接待をするかどうかだけでなく、建物の使われ方と用途地域もあわせて確かめる必要があります。

また、深夜0時から朝6時までの時間帯にお酒を出すことを営業の常態とするバーなどは、原則として[深夜酒類提供飲食店営業の届出](../late-night-liquor-notification-tokyo/)が必要です。ただし、通常主食と認められる食事を出すことが営業の中心になっている飲食店は、この届出の対象から外れます。

深夜にお酒を出しながら、お客様にショーなどを積極的に楽しんでもらう営業は、[特定遊興飲食店営業](../tokutei-yukyo-inshokuten/)に当たり、別に許可が必要になる場合があります。客にダンスをさせて飲食をさせるナイトクラブのような施設は、文教地区の制限の対象です。

## 商業地域でも文教地区がかかることがある

文教地区は用途地域とは別に指定されます。そのため、用途地域だけを見ると商業地域や近隣商業地域なのに、文教地区がかかっている場所があります。

たとえば台東区の都市計画マップ（たいとうマップ）で用途地域と文教地区を重ねて見ると、言問通り沿いや不忍通り沿いの一部は、用途地域が近隣商業地域などでありながら、第二種文教地区にも指定されています。「商業地域だからスナックを開ける」と考えて契約すると、あとで許可を受けられないことが分かる、ということにもなりかねません。

用途地域と文教地区は、区の都市計画図や、区のホームページの地図で確かめられます。境目は道路や敷地の途中にあることもあるので、物件の所在地を地図の上で確かめましょう。

## 風営法の距離の決まりとは別

文教地区の制限は建物の用途についての東京都の条例の決まりです。これとは別に、風営法と東京都の風営法施行条例には、学校や図書館、病院などの保護対象施設の周りで営業できない距離の決まりがあります。

文教地区に当たらない場所でも、近くに学校などがあれば、距離の決まりでお店を開けないことがあります。物件を探すときは両方を確かめる必要があります。

## 地域ごとの例

- [千代田区でスナック・バーを開くとき](../chiyoda-snack-bar-area/)：番町・富士見・神保町の文教地区
- [台東区でスナック・バーを開くとき](../taito-snack-bar-area/)：上野公園のまわりの第一種・第二種文教地区

## 物件を契約する前に

- 物件の所在地が、第一種・第二種の文教地区に当たらないか
- 開くお店が、文教地区で制限される用途（知事が指定する飲食店を含む）に当たらないか
- 用途地域や、学校・図書館・病院などとの距離の決まりも満たしているか
- 区の都市計画図で、境目が物件の近くを通っていないか

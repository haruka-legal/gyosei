夜のお店を開くとき、「許可の手続きは誰に頼めばいいのか」「行政書士にはどこまで任せられるのか」と迷う方は少なくありません。この記事では、スナック・ラウンジ・バーの開業や営業で、行政書士に頼めること・頼めないことを整理します。

## 手続きごとの依頼先（一覧）

| 頼みたいこと | 担当する専門家 |
| --- | --- |
| 風俗営業の許可申請、深夜酒類の届出、店内の図面、保健所・消防署の書類 | 行政書士 |
| 開店後の変更の届出、改装の承認申請 | 行政書士 |
| 会社を作る、役員を変える（法務局への登記） | 司法書士 |
| 確定申告、消費税などの税金の申告 | 税理士 |
| 雇用保険・社会保険の加入、労働基準監督署・年金事務所・ハローワークへの手続き | 社会保険労務士 |
| お客様・近隣・従業員とのトラブルの交渉、裁判、刑事事件の対応 | 弁護士 |
| 許可が出なかった・処分を受けたときの不服申立て | 弁護士、または法律で認められた範囲の特定行政書士 |

## 行政書士はどのような専門家か

行政書士は、行政書士法にもとづいて、主に次のような仕事をする国家資格者です。

- **役所に出す書類の作成**：許可の申請書や届出書、添付する図面など
- **権利や義務、事実を証明する書類の作成**：契約書など
- **役所への提出の代理**：作成した書類を、本人に代わって役所に出す
- **書類の作成についての相談**

風営法の手続きは、警察署を通して東京都公安委員会（警視庁を管理する、知事から独立した都の委員会）に書類を出すものなので、行政書士の仕事の中心になる分野のひとつです。

## 夜のお店の開業で行政書士に頼めること

**開業の前**

- **物件の事前調査**：用途地域や、学校・病院などの周りの施設を調べ、その物件で許可や届出ができるかを確かめます（詳しくは「[物件を契約する前に確認すること](../check-before-signing-lease/)」）
- **風俗営業の許可申請**：スナックやラウンジなど接待をするお店の許可（1号）の申請書類を作り、警察署に提出します
- **深夜酒類提供飲食店営業の届出**：接待をせずに深夜0時以降もお酒を出すお店の届出です
- **店内の図面の作成**：申請に必要な平面図、客室の面積を計算した図面、照明や音響設備の配置図などを作ります
- **保健所・消防署への手続き**：飲食店営業の許可の申請や、消防署への届出の書類も作成できます

**開店したあと**

- **変更の届出**：店名、管理者、会社の役員などが変わったときの届出です
- **店内の改装の手続き**：客室の造りや設備を変えるときの承認の申請や届出です
- **聴聞・弁明の手続き**：風俗営業の許可に関する処分などについて、行政書士法で認められた範囲で、聴聞や弁明の機会の手続きを代理します

**お店づくりに関わる書類**

- **会社を作るときの定款**：会社の基本ルールである定款の作成です（登記は司法書士が行います）
- **契約書**：お店とキャストの間の業務委託契約書など、権利や義務に関わる書類の作成です
- **外国籍のスタッフの在留資格の確認**：その在留資格で予定している仕事ができるかを確認します。留学生は、アルバイトの許可（資格外活動許可）があっても、風俗営業のお店では働けません。一方で、永住者や日本人の配偶者などのように、仕事の内容に制限のない在留資格もあります

## 行政書士に頼めないこと

ほかの法律で、別の専門家だけに認められている仕事は、行政書士は引き受けられません。夜のお店に関係するものは、冒頭の一覧のとおり、登記・税金・労働や社会保険の手続き・トラブルの対応などです。

不服申立ては、行政書士の中でも、所定の研修を修了した「特定行政書士」が、法律で認められた範囲で代理できます。

実際の開業では、「会社も作るし、スタッフも雇う」というように、いくつもの専門家が関わることがよくあります。手続き全体を整理して、必要な専門家につなぐことも、行政書士の役割です。

## 資格のない人に申請書類の作成を頼まない

内装業者や開業コンサルタントなどから、「許可の書類もこちらで作っておきます」と声をかけられることがあります。しかし、行政書士でない人が、他人の依頼を受けて報酬を得て、役所に出す書類を作ることは、行政書士法で原則として禁じられています（ほかの法律で認められている場合などを除きます）。

2026年1月1日に施行された行政書士法の改正では、「手数料」「コンサルタント料」など、どのような名目でお金を受け取っていても違反になることが、条文で明確になりました。違反した本人には罰則があり、会社の業務として違反が行われた場合は、その会社も罰せられることがあります。

もちろん、お店を開く本人が自分で書類を作って出すことはできます。頼む場合は、行政書士に頼むことで、書類の内容と手続きに責任を持つ専門家が関わることになります。

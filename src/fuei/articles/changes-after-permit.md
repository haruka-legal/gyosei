風俗営業の許可は、取ったら終わりではありません。営業を続けるうちに、店名を変える、管理者が代わる、店内を改装するといったことは珍しくありません。そのたびに、決められた手続きが必要になることがあります。この記事では、キャバクラやスナックなど風俗営業（1号）のお店が、許可を受けたあとに必要になる主な手続きを整理します。

## ひと目でわかる、変わったときの手続き

| こんなとき | 必要な手続き | いつまでに |
| --- | --- | --- |
| 店名や管理者が変わった | 変更の届出 | 変わった日から10日以内 |
| 会社の名前・住所・代表者の氏名、役員の氏名・住所が変わった | 変更の届出 | 変わった日から20日以内 |
| 客室の位置・数・広さ、仕切りなどを変える | 構造・設備の変更の承認 | 工事の前 |
| 小規模な修繕や模様替えなど、軽い変更をした | 変更の届出 | 変えた日から1か月以内 |
| 照明・音響・防音の設備を変えた | 変更の届出 | 変えた日から10日以内 |
| 許可証に書かれた内容が変わった | 許可証の書換え | 変更の届出とあわせて |
| 営業していた人が亡くなり、相続人が続ける | 相続の承認の申請 | 亡くなった日から60日以内 |
| 会社の合併・分割で引き継ぐ | 合併・分割の承認の申請 | 合併・分割の効力が生じる前 |
| お店の場所を移す、営業する人が変わる | 新しく許可を取り直す | 新しい営業を始める前 |
| 営業をやめた | 返納理由書を添えて許可証を返す | やめた日から10日以内 |

この表は、ふつうの風俗営業者向けです。特例風俗営業者は、構造・設備の変更の手続きが一部異なります。

## 店名や管理者、役員が変わったとき

許可を申請したときに届け出た内容のうち、次のものが変わったときは、変更の届出をします。

- **お店の名前（屋号）や管理者など**：変わった日から10日以内
- **会社の名前・住所・代表者の氏名、役員の氏名・住所**：変わった日から20日以内

管理者が変わった場合は、変更の届出に加えて、交付を受けている管理者証の提出が必要になることがあります。

役員が代わるだけなら、変更の届出で足ります。新しく許可を取り直す必要はありません。

管理者が辞めて次の人が決まっていない、役員が代わったのに届け出ていなかった、というのはよくある漏れです。どちらも、[警察の立入検査](../police-inspection-snack-bar/)で確かめられることがあります。

## 店内の造りを変えるとき

店内の構造や設備を変えるときは、変更の内容によって、必要な手続きが変わります。

- **工事の前に承認を受ける必要がある変更**：客室の位置や数、広さを変える、客室の中の仕切りを変える、大規模な修繕や模様替えをする、など
- **変えたあとに届け出ればよい変更**：小規模な修繕や模様替え、一定の家具の設置や入れ替えなどは、変えた日から1か月以内に届け出ます。照明・音響・防音の設備を変えたときは、10日以内です
- **手続きが要らない変更**：破れた壁紙の貼り替え、切れた電球を同じ規格のものに交換する、見通しをさえぎらない範囲で椅子やテーブルの配置を少し変える、などは届出が要りません

どれに当たるかは、変更の中身で決まります。承認が必要な変更を、承認を受けずに工事してしまうと違反になります。改装や模様替えを考えたら、工事の前に確かめることが大切です。

## 許可証の書換え

店名などの変更で、許可証に書かれている内容が変わったときは、許可証の書換えを申請します。古い内容のままの許可証を掲げていると、立入検査で指摘されることがあります。

## お店を引き継ぐとき

風俗営業の許可は、営業する人に対して与えられるものです。原則として、ほかの人に引き継ぐことはできません。

ただし、次の場合は、公安委員会の承認を受ければ許可を引き継げます。

- **相続**：営業していた人が亡くなり、相続人が営業を続ける場合。亡くなった日から60日以内に承認を申請します。申請した場合は、承認か不承認の結果が出るまで、もとの許可を相続人の許可とみなして営業を続けられます。相続人が複数いる場合は、営業を引き継ぐ相続人を決めます。承認を受けたあとは、許可証の書換えが必要です
- **会社の合併・分割**：許可を受けた会社が合併や分割をする場合。合併や分割の効力が生じる前に、承認を受けておく必要があります

事業譲渡（お店を売り買いすること）で許可を引き継ぐ制度はありません。お店を買い取って営業する場合は、新しく許可を取り直します。

## 新しく許可を取り直す必要がある場合

次のような場合は、変更の届出では済まず、新しく許可を取ります。

- お店の場所を移す
- 営業する人が変わる（相続・合併・分割で承認を受けた場合を除く）
- 個人で営業していたお店を、会社で営業するようにする

個人から会社に切り替える場合も、「営業する人」が変わることになるので、新しく許可を取り直します。

## 営業をやめたとき

営業をやめたときは、やめた日から10日以内に、返納理由書を添えて、お店の場所を管轄する警察署に許可証を返します。

## 東京都の手数料

東京都では、主な手続きの手数料は次のとおりです（警視庁関係手数料条例）。

| 手続き | 手数料 |
| --- | --- |
| 構造・設備の変更の承認 | 9,900円 |
| 許可証の書換え | 1,500円 |
| 許可証の再交付 | 1,200円 |
| 相続の承認 | 9,000円 |
| 合併・分割の承認 | 12,000円 |

複数のお店について同時に承認を申請する場合は、2店目から減額されるものもあります。変更の届出には、手数料はかかりません。

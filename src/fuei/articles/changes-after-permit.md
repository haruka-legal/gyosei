風俗営業の許可は、取ったら終わりではありません。営業を続けるうちに、店名を変える、管理者が代わる、店内を改装するといったことは珍しくありません。そのたびに、決められた手続きが必要です。この記事では、キャバクラやスナックなど風俗営業（1号）のお店が、許可を受けたあとに必要になる手続きを整理します。

## ひと目でわかる、変わったときの手続き

| こんなとき | 必要な手続き | いつまでに |
| --- | --- | --- |
| 店名、管理者、役員、営業時間などが変わった | 変更の届出 | 変わった日から10日以内（会社の名前・住所・代表者など、登記が関わる変更は20日以内） |
| 客室の造りや設備を変える | 構造・設備の変更の承認、または変更の届出 | 承認が必要なものは工事の前 |
| 許可証に書かれた内容が変わった | 許可証の書換え | 変更の届出とあわせて |
| お店を引き継ぐ（相続・会社の合併・分割） | 承認の申請 | 相続は亡くなった日から60日以内など |
| お店の場所を移す、営業する人が変わる | 新しく許可を取り直す | 営業を始める前 |
| 営業をやめた | 廃止の届出と許可証の返納 | やめた日から10日以内 |

## 店名や管理者、役員が変わったとき

許可を申請したときに届け出た内容が変わったときは、変更の届出をします。主なものは次のとおりです。

- お店の名前（屋号）
- 管理者
- 会社の名前、住所、代表者、役員
- 営業時間などの営業の方法

期限は、原則として変わった日から10日以内です。会社の名前や住所、代表者など、登記事項証明書を出す必要がある変更は20日以内です。

管理者が辞めて次の人が決まっていない、役員が代わったのに忘れていた、というのはよくある漏れです。どちらも、[警察の立入検査](../police-inspection-snack-bar/)で確かめられることがあります。

## 店内の造りを変えるとき

客室の広さや仕切り、照明、音響など、店内の構造や設備を変えるときは、注意が必要です。

- **事前に承認を受ける必要がある変更**：客室の造りに関わる増築や改築など、変更の内容によっては、工事を始める前に公安委員会の承認を受けなければなりません
- **あとから届け出ればよい変更**：比較的軽い変更は、変更の届出で済む場合があります

どちらに当たるかは、変更の内容によって決まります。承認が必要な変更を、承認を受けずに工事してしまうと、違反になります。改装や模様替えを考えたら、工事の前に確かめることが大切です。

## 許可証の書換え

店名などの変更で、許可証に書かれている内容が変わったときは、許可証の書換えを申請します。古い内容のままの許可証を掲げていると、立入検査で指摘されることがあります。

## お店を引き継ぐとき

風俗営業の許可は、営業する人に対して与えられるものです。原則として、ほかの人に引き継ぐことはできません。

ただし、次の場合は、公安委員会の承認を受ければ許可を引き継げます。

- **相続**：営業していた人が亡くなり、相続人が営業を続ける場合
- **会社の合併**：許可を受けた会社が合併する場合
- **会社の分割**：許可を受けた会社が分割する場合

事業譲渡（お店を売り買いすること）で許可を引き継ぐ制度はありません。お店を買い取って営業する場合は、新しく許可を取り直します。

## 新しく許可を取り直す必要がある場合

次のような場合は、変更の届出では済まず、新しく許可を取ります。

- お店の場所を移す
- 営業する人が変わる（相続・合併・分割で承認を受けた場合を除く）
- 個人で営業していたお店を、会社で営業するようにする

個人から会社に切り替える場合も、「営業する人」が変わることになるので、新しく許可を取り直します。

## 営業をやめたとき

営業をやめたときは、やめた日から10日以内に、廃止の届出をし、許可証を返します。

## 東京都の手数料

東京都では、主な手続きの手数料は次のとおりです（警視庁関係手数料条例）。

| 手続き | 手数料 |
| --- | --- |
| 構造・設備の変更の承認 | 9,900円 |
| 許可証の書換え | 1,500円 |
| 許可証の再交付 | 1,200円 |
| 相続の承認 | 9,000円 |
| 合併・分割の承認 | 12,000円 |

変更の届出そのものには、手数料はかかりません。

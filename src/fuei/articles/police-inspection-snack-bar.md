スナックやバーを開いてしばらくすると、営業中に警察官が来て、店内や書類を確かめていくことがあります。「立入検査」と呼ばれるものです。キャバクラやガールズバーも同じです。初めてだと驚くと思いますが、どんなことを見られるかを知っておけば、落ち着いて対応できます。

この記事では、風俗営業（1号）のお店と、深夜酒類提供飲食店営業のお店を対象に説明します。性風俗のお店は見られるところが違うので、ここでは扱いません。

## 立入検査とは

風営法では、警察職員が風俗営業や深夜酒類提供飲食店営業などのお店に立ち入り、営業の様子を確かめることができると定めています。

- **目的**：お店が風営法の決まりを守って営業しているかを確かめるためのものです
- **身分証の提示**：立ち入る警察職員は、身分を示す証明書を持ち、求められれば見せなければなりません
- **捜査とは違う**：法律で、この立入りは犯罪捜査のために認められたものと考えてはならない、とされています

お店に落ち度がなくても来ることがあります。立入検査があったからといって、違反を疑われているとは限りません。

## よく確かめられるところ

| 確かめられること | 内容 |
| --- | --- |
| 許可証の掲示 | 風俗営業の許可証（原本）が、お店の見やすい場所に掲げてあるか。店名などが変わったのに、古いままになっていないか |
| 従業者名簿 | スタッフの名簿があるか。辞めた人の分も決められた期間保存しているか |
| 接客スタッフの確認の記録 | 生年月日や国籍、外国籍の方の在留資格などを確かめた記録と、確かめた書類の写しがあるか |
| 料金の表示 | 風俗営業のお店で、料金がお客様にわかるように表示されているか |
| 営業時間 | 風俗営業のお店が、原則として深夜0時を過ぎて営業していないか |
| 店内の造り | 客室の広さや仕切り、照明の明るさなどが、許可を受けたときの図面と同じか。勝手に変えていないか |
| 18歳未満の方の扱い | 18歳未満の方をお客様として入れていないか、働かせていないか。入口に18歳未満の方の立入りを禁止する表示があるか（風俗営業のお店） |
| 接待の有無 | 深夜酒類の届出だけのお店で、スタッフが接待をしていないか |

特に気をつけたいのは、「店内の造り」と「接待の有無」です。棚やパーテーションを置いて見通しが悪くなった、照明を暗くしたといった小さな変更でも、許可を受けたときの造りと違えば問題になります。深夜酒類の届出だけのお店で[接待にあたる接客](../what-counts-as-settai/)をしていれば、無許可営業を疑われます。

## すぐ出せるようにしておくもの

立入検査では、書類を見せるよう求められることがあります。次のものは、お店の中のわかる場所にまとめておくと安心です。

- 風俗営業の許可証（掲示しているもの）、または深夜酒類提供飲食店営業の届出書の控え
- 従業者名簿
- 接客スタッフの生年月日や在留資格などを確かめた記録と、確かめた書類の写し
- 許可を受けたときの図面の控え

管理者や店長がいない時間帯にも、ほかのスタッフが書類の場所を答えられるようにしておきます。

## 立入りを断ったらどうなる？

正当な理由なく立入りを拒んだり、邪魔をしたりすると、罰則の対象になります。立入検査には協力するのが基本です。

一方で、立ち入る人が身分を示す証明書を見せない場合や、個室にお客様がいる場合など、確かめておきたいこともあります。わからないことがあれば、その場で落ち着いて尋ねて大丈夫です。

## 指摘を受けたあとの流れ

立入検査で決まりに合っていないところが見つかると、まずは直すように「指示」を受けることが多いです。指示に従って直せば、それで終わることがほとんどです。

ただ、直さずに営業を続けたり、違反が重かったりすると、営業停止や許可の取消しといった処分を受けることがあります。許可を取り消されると、その後しばらくは新しく許可を受けられません。

## 普段からしておくこと

- **造りを変えるときは先に相談する**：客室の仕切りや照明などを変えるときは、変更の手続きが必要になることがあります
- **名簿と記録をため込まない**：スタッフが入ったとき、辞めたときに、その日のうちに名簿を更新する
- **届け出た内容が変わったら届け出る**：管理者や役員、店名が変わったときは、変更の届出が必要です
- **スタッフに伝えておく**：立入検査が来たときに誰が対応するか、書類はどこにあるかを決めておく

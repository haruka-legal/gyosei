スナックやバーを営業していると、営業中に警察官が来て、店内や書類を確かめていくことがあります。「立入検査」と呼ばれるものです。キャバクラやガールズバーなど、風俗営業や深夜酒類提供飲食店営業にあたるお店も対象になります。どんなことを確かめられるかを知っておけば、落ち着いて対応できます。

この記事では、風俗営業（1号）のお店と、深夜酒類提供飲食店営業のお店について説明します。性風俗関連特殊営業は規制の内容が異なるため、ここでは扱いません。

## 立入検査とは

風営法では、警察職員が風俗営業や深夜酒類提供飲食店営業などのお店に立ち入り、営業の様子を確かめることができると定めています。

- **目的**：お店が風営法の決まりを守って営業しているかを確かめるためのものです
- **身分証の提示**：立ち入る警察職員は、身分を示す証明書を持ち、お店の関係者に見せなければなりません
- **捜査とは違う**：法律で、この立入りは犯罪捜査のために認められたものと考えてはならない、とされています（別に犯罪の捜査が行われることまで否定するものではありません）

立入検査は、違反が見つかったお店だけに行われるものではありません。立入検査があったからといって、違反を疑われているとは限りません。

## 立入検査で確認される主な項目

| 確認されること | 内容 |
| --- | --- |
| 許可証の掲示 | 風俗営業の許可証が、原本で（コピーは不可）、お店の見やすい場所に掲げてあるか。店名などが変わったのに、古いままになっていないか |
| 従業者名簿 | 接客スタッフに限らず、営業に関わるスタッフの名簿があるか（一定の業務委託のスタッフも含みます）。辞めた人の分も、辞めてから3年間保存しているか |
| 接客スタッフの確認の記録 | お客様に接するスタッフの生年月日や国籍、外国籍の方の在留資格などを確かめた記録があるか。辞めてから3年間保存しているか |
| 料金の表示 | 風俗営業のお店で、料金がお客様にわかるように表示されているか |
| 営業時間 | 風俗営業のお店が、原則として深夜0時を過ぎて営業していないか |
| 店内の造り | 客室の広さや仕切り、照明の明るさなどが、許可を受けたときの内容や基準に合っているか |
| 18歳未満の方の扱い（風俗営業） | 18歳未満の方をお客様として入れていないか、接待をさせていないか。入口に18歳未満の方の立入りを禁止する表示があるか |
| 18歳未満の方の扱い（深夜酒類） | 深夜の時間帯の18歳未満の方の扱いが、決まりに合っているか（時間帯や営業の内容によって決まりが異なります） |
| 接待の有無 | 深夜酒類の届出だけのお店で、スタッフが接待をしていないか |

特に気をつけたいのは、「店内の造り」と「接待の有無」です。棚やパーテーションの設置、照明の変更などは、内容によって事前の承認や変更の届出が必要になることがあります。変えたあとの店内が基準に合っているかも大切です。深夜酒類の届出だけのお店で[接待にあたる接客](../what-counts-as-settai/)をしていれば、無許可営業を疑われます。

## すぐ出せるようにしておくもの

立入検査では、書類を見せるよう求められることがあります。店内の決まった場所にまとめておくと安心です。

**法律で備えておくことが決められているもの**

- 風俗営業の許可証（掲示しているもの）
- 従業者名簿
- 接客スタッフの生年月日や在留資格などを確かめた記録

**決まりではないが、手元にあると役立つもの**

- 深夜酒類提供飲食店営業の届出書の控え（警察署の受付印があるもの）。深夜酒類には許可証がないので、届出をしたことを示す書類になります
- 許可を受けたときの図面の控え。店内の造りを変えていないかを確かめるときに役立ちます

管理者や店長がいない時間帯にも、ほかのスタッフが書類の場所を答えられるようにしておきます。

## 立入りを断ったらどうなる？

正当な理由なく立入りを拒んだり、邪魔をしたりすると、罰則の対象になります。立入検査には協力するのが基本です。

ただし、風営法にもとづく立入りには範囲の決まりがあります。たとえば、お客様がいる個室などは、原則として立入りの対象になりません。また、警察職員は身分を示す証明書を見せる必要があります。疑問がある場合は、その場で落ち着いて確かめましょう。

## 指摘を受けたあとの流れ

立入検査で違反が見つかった場合、内容に応じて改善を求められたり、行政処分を受けたりすることがあります。

風俗営業では、公安委員会が法律にもとづく「指示」の処分をすることがあります。また、違反の内容や程度によっては、営業停止や許可の取消しの対象になることもあります。深夜酒類のお店も、営業の停止などを命じられることがあります。

指摘されたからといって、必ず営業停止になるわけではありません。一方で、改善すれば必ず処分を受けずに済む、というわけでもありません。何が問題とされているのか、どう対応すればいいのかを確かめて、速やかに対応することが大切です。

## 普段からしておくこと

- **造りを変えるときは先に確かめる**：客室の仕切りや照明などを変えるときは、内容によって事前の承認や変更の届出が必要です
- **名簿や確認の記録をこまめに更新する**：スタッフが入ったとき、辞めたときに、その日のうちに更新する
- **変更があったら必要な手続きをする**：管理者や役員、店名などが変わったときは、変更の届出が必要です
- **スタッフに伝えておく**：立入検査が来たときに誰が対応するか、書類はどこにあるかを決めておく

「妻にお店を持たせてあげたい」「妻の得意な接客を生かしてスナックをやりたい」。外国籍の奥さんをママにして、夫婦でお店を始めたいというご相談は少なくありません。

奥さんの在留資格によっては、日本人と同じようにお店を経営できます。ただ、夫婦で始めるからこそ気をつけたい点もあります。この記事では奥さんをママにしてスナックを開くまでの流れを、工程の順に説明します。

## 開店までの流れ

1. だれの名前で営業するかを決める
2. 奥さんの在留資格を確かめる
3. 物件を探す
4. 内装工事をする
5. 許可を申請する
6. 従業員を集める

## 1. だれの名前で営業するかを決める

最初に決めるのは、お店の営業者をだれにするかです。主に次の3つの形があります。

| 営業者 | 特徴 |
| --- | --- |
| 奥さん個人 | 奥さんが自分のお店として経営する。売上や経費も奥さんの事業になる |
| 旦那さん個人 | 旦那さんが営業者になり、奥さんをママ（管理者）にする |
| 旦那さんの会社 | 会社の事業としてお店を営業する。会社の目的に飲食店の経営が入っていなければ、目的を変える登記が必要 |

どの形でも、許可を受けた人が実際にお店を営業する必要があります。たとえば許可は旦那さんの名前で受けて、実際の経営はすべて奥さんが一人でしているような形は、風営法で禁止されている名義貸し（風営法11条）に当たるおそれがあります。実際にお店を経営する人の名前で許可を受けましょう。

風俗営業の許可では、営業者（会社の場合は役員全員）が欠格事由に当たらないかを確かめられます。旦那さんの会社で申請する場合は、お店に関わらない役員の書類も必要になります。

## 2. 奥さんの在留資格を確かめる

在留カードの在留資格を見てください。

| 奥さんの在留資格 | ママ・経営者になれるか |
| --- | --- |
| 日本人の配偶者等・永住者・永住者の配偶者等・定住者 | なれる（仕事の制限がない） |
| 留学・家族滞在 | なれない（資格外活動許可があっても、風俗営業のお店では働けない） |
| 技術・人文知識・国際業務などの就労の在留資格 | 原則としてなれない |

日本人の旦那さんと結婚している奥さんの多くは「日本人の配偶者等」です。この在留資格なら、ママとして接客することも、自分でお店を経営することもできます。

一方、日本人の配偶者等は結婚していることが前提の在留資格です。離婚した場合は、そのままの在留資格で日本に住み続けられなくなることがあり、別の在留資格に変える手続きが必要になります。奥さん名義でお店を経営する場合は、この点も知っておくと安心です。[外国籍の方がお店を経営するとき](../foreign-owner-night-business/)の在留資格の考え方もあわせて確かめてください。

## 3. 物件を探す

スナックで客席に座ってお話をする、お酒をつくって一緒に飲むといった接客は、風営法の「接待」に当たります。接待をするお店は風俗営業の許可が必要で、許可を受けられない場所があります。

住宅の多い地域や、学校・保育所・病院などの近くでは許可を受けられないことがあります。物件は[契約する前に許可が取れる場所か確かめる](../check-before-signing-lease/)ことが大切です。

## 4. 内装工事をする

風俗営業の許可には、お店の造りにも決まりがあります。主なものは次のとおりです。

- 客室の中に、見通しをさえぎる仕切りや高い設備を置かない
- 客室の明るさが5ルクス以上ある
- 客室が2室以上ある場合、1室の広さが16.5平方メートル以上ある

旦那さんが内装の仕事をしている場合、工事を自分たちでできるのは大きな強みです。ただし、許可の申請では店内の図面を出し、警察が実際のお店を見て図面のとおりか確かめます。工事をしてから決まりに合わないことがわかると、やり直しになります。工事の前に図面を決めておきましょう。

許可を受けたあとに客室の仕切りや広さを変える場合も、工事の前に公安委員会の承認が必要です。

## 5. 許可を申請する

スナックを開くには、主に次の2つの手続きが必要です。

- **飲食店営業の許可**：保健所に申請する
- **風俗営業の許可**：お店の場所を受け持つ警察署を通じて申請する

風俗営業の許可は、東京都では申請してから結果が出るまで、55日以内（休日を除く）が目安です。許可が出るまではお店を開けないので、家賃がかかり始める時期と開店日は余裕をもって決めましょう。

お店ごとに、業務を管理する「管理者」を1人決めます。奥さんがママとしてお店に立つなら、奥さんを管理者にするのが自然です。管理者は従業員の指導やお店の管理をする立場で、警察の[立入検査](../police-inspection-snack-bar/)のときにも対応します。

## 6. 従業員を集める

夫婦で始めるお店で最も気をつけたいのが、従業員の在留資格です。奥さんの友人や同じ国の知り合いに手伝ってもらう場合でも、在留資格によっては働けません。

| 在留資格 | スナックで働けるか |
| --- | --- |
| 日本人の配偶者等・永住者・永住者の配偶者等・定住者 | 働ける |
| 留学・家族滞在 | 働けない（資格外活動許可があっても、風俗営業のお店では、接客をしないキッチンや清掃の仕事もできない） |
| 特定技能・技能実習・技術・人文知識・国際業務など | 働けない（決められた仕事以外はできない） |
| 短期滞在（観光などで来日している方） | 働けない |

奥さんの家族が母国から遊びに来ていて、お店を手伝ってもらうケースもあります。短期滞在の方は日本で働くことができません。報酬を払わない手伝いのつもりでも、実態によっては働いていると判断されるおそれがあります。

働けない方を働かせると、お店の経営者や会社が不法就労助長罪に問われます。現在の罰則は3年以下の拘禁刑か300万円以下の罰金、またはその両方です。2027年4月1日からは、5年以下の拘禁刑か500万円以下の罰金、またはその両方に引き上げられます。「知らなかった」では済まされないため、雇う前に[在留カードの確かめ方](../foreign-staff-night-business/)を押さえておきましょう。

また、日本人・外国人にかかわらず、18歳未満の方に接待をさせることはできません。

## 接待をしないバーから始める方法もある

カウンター越しにお酒を出すだけで、客席に座ったりお客様と一緒に歌ったりしないお店なら、風俗営業の許可はいりません。深夜0時以降もお酒を出す場合は、深夜酒類提供飲食店営業の届出をします。

ただし、ママがお客様の隣に座ってお話をすると、接待に当たることがあります。どこからが接待になるかは[接待に当たる接客](../what-counts-as-settai/)を確かめてから、お店の形を決めましょう。

## 開店したあとに気をつけること

- **税金**：お店の売上はだれの事業の売上になるかで、確定申告をする人が変わります。奥さんを扶養に入れたままでいられるかも変わるため、開店前に税理士に相談しておくと安心です
- **届出**：管理者や店名が変わったときは、10日以内に届出が必要です
- **従業員の記録**：接客をする従業員の生年月日や在留資格を確かめた記録を、お店で保存しておく必要があります

夫婦で始めるお店は、だれの名前で、だれが何を担当するかを最初にはっきりさせておくことが大切です。

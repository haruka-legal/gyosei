「妻に自分のお店を持ってほしい」「妻の得意な接客を生かしてスナックをやりたい」。外国籍の妻をママにして、夫婦でお店を始めたいというご相談は少なくありません。

妻の在留資格によっては、日本人と同じようにお店を経営できます。ただ、夫婦で始めるからこそ気をつけたい点もあります。この記事では妻をママにしてスナックを開くまでの流れを、工程の順に説明します。

## 開店までの流れ

1. 妻の在留資格を確かめる
2. だれの名前で営業するかを決める
3. 営業できる場所か確かめて物件を探す
4. 決まりに合わせて内装を設計・工事する
5. 飲食店営業の許可と風俗営業の許可を申請する
6. 従業員の在留資格を確かめて開店の準備をする

## 1. 妻の在留資格を確かめる

最初に妻の在留カードを見て、在留資格を確かめます。在留資格によって、ママとして働けるか、自分でお店を経営できるかが変わるためです。

| 妻の在留資格 | ママ・経営者になれるか |
| --- | --- |
| 日本人の配偶者等・永住者・永住者の配偶者等・定住者 | なれる（仕事の制限がない） |
| 留学・家族滞在 | なれない（資格外活動許可を受けていても、スナックで働くことは認められない） |
| 技術・人文知識・国際業務などの就労の在留資格 | 現在の在留資格のままでは、通常はなれない |

日本人の夫と結婚している妻の多くは「日本人の配偶者等」です。この在留資格なら、ママとして接客することも、自分でお店を経営することもできます。

### 在留資格が変わる場合の注意点

日本人の配偶者等は、結婚していることが前提の在留資格です。離婚や死別をしたときは、14日以内に出入国在留管理庁へ届け出る必要があります。配偶者としての活動をしないまま6か月以上たつと、正当な理由がある場合を除いて在留資格を取り消される対象になります。日本に住み続けるには、それまでの生活の状況などに応じて、定住者など別の在留資格に変えられるかを検討することになります。

妻の名前でお店を経営する場合は、在留期限の管理とあわせて、この点も知っておくと安心です。留学・家族滞在や就労の在留資格の方が経営する場合の考え方は、[外国籍の方がお店を経営するとき](../foreign-owner-night-business/)の在留資格の条件を確かめてください。

## 2. だれの名前で営業するかを決める

在留資格を確かめたら、お店の営業者をだれにするかを決めます。主に次の3つの形があります。

| 営業者 | 特徴 |
| --- | --- |
| 妻個人 | 妻が自分のお店として経営する。売上や経費も妻の事業になる |
| 夫個人 | 夫が営業者になり、妻をママ（管理者）にする |
| 夫の会社 | 会社の事業としてお店を営業する。会社の目的を確かめ、必要なら目的を変える登記をする |

どの形でも、許可を受けた人が実際にお店を営業する必要があります。たとえば許可は夫の名前で受けて、実際の経営はすべて妻が一人でしているような形は、風営法で禁止されている名義貸し（風営法11条）に当たるおそれがあります。妻の在留資格が経営を認めていないものであれば、入管法の問題にもなりかねません。実際にお店を経営する人の名前で許可を受けましょう。

風俗営業の許可では、営業者（会社の場合は役員全員）が欠格事由に当たらないかを確かめられます。夫の会社で申請する場合は、お店に関わらない役員の書類も必要になります。

## 3. 営業できる場所か確かめて物件を探す

スナックで特定のお客様のそばに付いて続けて談笑したり、お酌をしたりする接客は、風営法の「接待」に当たります。接待をするお店は接待を伴う飲食店（風営法2条1項1号）として風俗営業の許可が必要で、許可を受けられない場所があります。

住宅の多い地域や、学校・保育所・病院などの近くでは許可を受けられないことがあります。物件は[契約する前に許可が取れる場所か確かめる](../check-before-signing-lease/)ことが大切です。

## 4. 決まりに合わせて内装を設計・工事する

風俗営業の許可には、お店の造りにも決まりがあります（風営法施行規則7条）。主なものは次のとおりです。

- 客室の中に、見通しをさえぎる仕切りや高い設備を置かない
- 客室の出入口に鍵を付けない（お店の外に直接出られる出入口は除く）
- お店の中の照度が5ルクス以下とならないように照明を設ける。照度を5ルクス以下に自由に落とせる調光器は付けられない
- 客室が2室以上ある場合、1室の広さを16.5平方メートル以上（和風の客室は9.5平方メートル以上）にする
- 騒音や振動が条例で決められた数値を超えない造りにする

夫が内装の仕事をしている場合、工事を自分たちでできるのは大きな強みです。ただし、許可の申請では店内の図面を出し、警察が実際のお店を見て図面のとおりか確かめます。工事をしてから決まりに合わないことがわかると、やり直しになります。工事の前に図面を決めておきましょう。

許可を受けたあとに客室の位置や広さ、仕切りなどを変える場合は、原則として工事の前に公安委員会の承認が必要です。小さな修繕などは変えたあとの届出で足りるものもありますが、どれに当たるかは[許可を取ったあとに必要な手続き](../changes-after-permit/)を確かめてから工事を始めましょう。

## 5. 飲食店営業の許可と風俗営業の許可を申請する

スナックを開くには、主に次の2つの手続きが必要です。

- **飲食店営業の許可**：保健所に申請する
- **風俗営業の許可**：お店の場所を受け持つ警察署を通じて申請する

風俗営業の許可は、東京都では申請してから結果が出るまで、55日以内（休日を除く）が目安です。許可が出るまではお店を開けないので、家賃がかかり始める時期と開店日は余裕をもって決めましょう。

お店ごとに、業務を管理する「管理者」を1人決めます（風営法24条）。妻が実際にお店の業務を管理していて、管理者になれない条件に当たらなければ、妻を管理者にできます。管理者は原則として、そのお店に常勤して管理の仕事ができる人である必要があります。従業員の指導やお店の管理をする立場で、警察の[立入検査](../police-inspection-snack-bar/)のときにも対応します。

## 6. 従業員の在留資格を確かめて開店の準備をする

夫婦で始めるお店で最も気をつけたいのが、従業員の在留資格です。妻の友人や同じ国の知り合いに手伝ってもらう場合でも、在留資格によっては働けません。

| 在留資格 | スナックで働けるか |
| --- | --- |
| 日本人の配偶者等・永住者・永住者の配偶者等・定住者 | 働ける |
| 留学・家族滞在 | 働けない（資格外活動許可を受けていても、接待をしないキッチンや清掃の仕事も含めて働けない） |
| 特定技能・技能実習・技術・人文知識・国際業務など | 通常は働けない（現在の在留資格で認められた仕事の範囲に入らない） |
| 短期滞在（観光などで来日している方） | 働けない |

技能実習は2027年4月1日から、[育成就労](../../../gyosei/articles/ikusei-shuro/)という新しい制度に変わります。

2026年10月1日から、家族滞在の方に限り、個別の資格外活動許可を受ければパチンコ店などの遊技場で働けるようになりました。対象は風営法2条1項4号・5号の営業だけで、スナックなどの接待を伴う飲食店は含まれません。

雇う前には在留カードやパスポート、資格外活動許可の内容を確かめ、その方が実際に担当する仕事をできるか確かめましょう。確かめ方は[在留カードの確かめ方](../foreign-staff-night-business/)を参考にしてください。

妻の家族が母国から遊びに来ていて、お店を手伝ってもらうケースもあります。短期滞在の方は日本で働くことができません。報酬を払わない手伝いのつもりでも、お小遣いや食事などのお礼が手伝いの対価とみなされるなど、実態によっては働いていると判断されるおそれがあります。家族であってもお店の仕事は手伝ってもらわないのが安全です。

就労が認められていない方を働かせると、お店の経営者や会社が不法就労助長罪に問われるおそれがあります。現在の罰則は3年以下の拘禁刑か300万円以下の罰金、またはその両方です。2027年4月1日からは、5年以下の拘禁刑か500万円以下の罰金、またはその両方に引き上げられます。「知らなかった」では済まされません。

また、日本人・外国人にかかわらず、18歳未満の方に接待をさせることはできません。午後10時から朝6時までの間に、18歳未満の方にお客様と接する仕事をさせることもできません（風営法22条1項）。

## 接待をしない飲食店から始める方法もある

カウンターの中で注文に応じてお酒を出し、あいさつや少しの世間話をする程度のお店なら、通常は接待に当たらず、風俗営業の許可はいりません。深夜0時以降も主にお酒を出して営業する場合は、深夜酒類提供飲食店営業の届出が必要です。ただし、住宅の多い地域など、深夜にお酒を出す営業ができない場所もあります。

ただし、カウンター越しでも特定のお客様と続けて談笑の相手をしていると、接待に当たることがあります。ママがお客様の隣に座ってお話をすれば、なおさらです。どこからが接待になるかは[接待に当たる接客](../what-counts-as-settai/)を確かめてから、お店の形を決めましょう。

## 開店したあとに気をつけること

- **税金**：お店の売上はだれの事業の売上になるかで、確定申告をする人が変わります。妻を扶養に入れたままでいられるかも変わるため、開店前に税理士に相談しておくと安心です
- **変更の届出**：店名や管理者を変えたときは、原則として変わった日から10日以内に届け出ます。会社の役員などが変わったときは20日以内です。変わった内容によって期限や手続きが違います
- **従業者名簿**：お店ごとに従業者名簿を備え、働く人の住所や氏名などを書いておきます（風営法36条）
- **接客をする従業員の確認と記録**：お客様と接する仕事をする従業員について、生年月日や国籍、外国籍の方は在留資格や在留期間などを決められた書類で確かめ、その記録を保存します（風営法36条の2）
- **外国人雇用状況の届出**：外国籍の従業員を雇ったときや辞めたときは、ハローワークに届け出ます（特別永住者の方などは対象外）

夫婦で始めるお店は、だれの名前で、だれが何を担当するかを最初にはっきりさせておくことが大切です。

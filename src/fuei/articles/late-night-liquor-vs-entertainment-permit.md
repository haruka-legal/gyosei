夜にお酒を出すお店を開くとき、多くの方が迷うのが「深夜酒類の届出にするか、風俗営業の許可（1号）を取るか」です。警察庁のまとめでは、2025年（令和7年）末の時点で、全国の深夜酒類の届出が約25万8千件、1号の許可が約6万件あり、夜のお店の多くはこのどちらかで営業しています。

この記事では、主に東京都でお店を開く方に向けて、2つの違いを比べたうえで、どのように選べばよいかを説明します。営業時間や場所の基準など細かい決まりは都道府県によって異なるため、東京都以外の方はお店のある地域の警察署などでご確認ください。お酒を出すお店に必要な手続きの全体は、「[スナック・バー・ガールズバーの開業に必要な許可と届出](../permits-by-business-type/)」で整理しています。

## 深夜酒類と1号の違い（一覧）

| 比べる点 | 深夜酒類提供飲食店営業の届出 | 風俗営業の許可（1号） |
| --- | --- | --- |
| 手続きの種類 | 届出（期限までに書類を出す） | 許可（警察の審査を経て認められる） |
| 接待 | できない | できる |
| 深夜0時〜午前6時の営業 | できる | 原則できない（東京都の一部の商業地域は午前1時まで） |
| 手続きの時期 | 営業開始の10日前までに届け出る | 開店予定日から逆算して申請する（東京都では審査に55日以内が目安。休日を除く） |
| 窓口 | お店の場所を管轄する警察署 | お店の場所を管轄する警察署 |
| お店を出せない場所 | 住居集合地域では深夜営業ができない | 住居集合地域（住居系の用途地域）、学校・病院などの周辺（商業地域では緩められている場合あり） |
| 客室の広さ（客室が2室以上の場合） | 1室9.5㎡以上 | 1室16.5㎡以上（和室は9.5㎡以上） |
| 店内の明るさ | 20ルクス以下にならないこと | 5ルクス以下にならないこと |
| 従業者名簿 | 必要 | 必要 |

どちらも、保健所の飲食店営業の許可と消防署への届出が前提になります。そのうえで、風営法の手続きとしてこのどちらかを選ぶ形です。

## それぞれを選んだ場合のメリットと気をつけること

### 深夜酒類の届出を選ぶ場合

**向いているお店**：バー、ダイニングバー、接待をしないガールズバーなど、「遅い時間に来るお客様が多い」「お酒そのものを楽しんでもらう」お店です。

**できること**

- 深夜0時以降も、朝までお酒を出して営業できる
- 許可ではなく届出なので、審査を待つ期間がない（営業を始める10日前までに届け出ます）
- 客室の広さなどの基準が1号より緩い

**気をつけること**

- **接待はできない**：カウンターの中で注文に応じてお酒を出す、挨拶や少しの世間話をする、といった範囲にとどめます。カウンター越しであっても、特定のお客様の談笑の相手を続けていれば接待に当たる場合があります
- **住宅地では深夜営業ができない**：東京都では、条例で定める「住居集合地域」（住居系の用途地域）で、深夜0時から午前6時までお酒を出す営業が禁止されています
- **主食を出すお店は対象外になる場合がある**：ご飯もの、パン、麺類、ピザ、お好み焼きなどを、営業時間中いつも出していて、お客様の多くが食事をしに来るようなお店（定食屋やラーメン店など）は、この届出の対象になりません。一方で、メニューにパスタやチャーハンがあっても、お客様の多くがお酒を飲みに来るバーや、飲んだあとの締めにお茶漬けを出す程度のお店は、届出が必要です
- **深夜に遊興をさせない**：深夜にダンスやショーなどの遊興をさせる場合は、特定遊興飲食店営業の許可が別に必要です

### 風俗営業の許可（1号）を選ぶ場合

**向いているお店**：スナック、ラウンジ、キャバクラ、ホストクラブなど、「会話そのものがお店の売り」というお店です。

**できること**

- スタッフがお客様の隣に座って会話をしたり、続けてお酌をしたりする「接待」ができる
- 接待を前提にした料金の設定や、指名などのお店づくりができる

**気をつけること**

- **深夜0時で閉める**：東京都では、一部の商業地域に限って午前1時まで延長できます
- **場所の条件が厳しい**：東京都の条例で定める「住居集合地域」（住居系の用途地域）では原則として許可を受けられず、学校・病院・図書館・児童福祉施設などの周辺も制限されます
- **開店までに時間がかかる**：東京都では、審査だけで55日以内（休日を除く）が目安です。図面の作成や書類の準備を含めると、さらに時間を見ておく必要があります
- **店内の基準がある**：客室の広さ、外からの見通し、照明の明るさ、出入口に鍵をつけないことなどの基準を満たす必要があります

## どのように選ぶか

迷ったときは、次の3つを順に考えると整理しやすくなります。

1. **スタッフが特定のお客様の相手を続けてするか**（隣に座る、続けて談笑やお酌をするなど）：する → 1号。しない → 深夜酒類、または0時までに閉めるなら風営法の手続きは不要
2. **深夜0時以降も営業したいか**：したい → 深夜酒類（接待はしない）。0時までに閉める → 1号でも可
3. **候補の物件で、その手続きが取れるか**：用途地域と周辺の施設、客室の広さと間取りを、契約の前に確認する

特に気をつけたいのは、「深夜酒類で届け出たけれど、実際には接待をしている」という状態です。接待に当たるかどうかは、お店の呼び方ではなく実際の接客の仕方で判断されます。許可を受けずに接待をすると無許可営業となり、2025年6月の法改正で罰金の上限は1,000万円（法人は3億円）に引き上げられています。

「本当は接待をしたいけれど、深夜まで営業したい」という場合は、どちらかをあきらめる必要があります。開店してから形を変えようとすると、物件や内装を一からやり直すことにもなりかねません。物件探しの段階で、どちらの形で営業するかを決めておくことが大切です。

スナックやバー、キャバクラを始めるとき、「どんなお店にするか」と同じくらい大事なのが、「どうやって始めるか」です。何もない物件から作るのか、前のお店の内装を使うのか、お店や会社ごと買い取るのか。始め方によって、許可や届出で気をつけることが変わります。この記事では、主な5つの始め方を比べます。

## まず、どんなお店にどの手続きが必要か

始め方の前に、お店の営業の形によって、必要な手続きが違うことを押さえておきます。

| お店の営業の形 | 主に必要な手続き |
| --- | --- |
| 居酒屋など、ふつうの飲食店 | 保健所の飲食店営業許可 |
| 接待をするスナック、ラウンジ、キャバクラ | 飲食店営業許可＋風俗営業の許可（1号） |
| 接待をしないで、深夜0時以降もお酒を出すバー | 飲食店営業許可＋深夜酒類提供飲食店営業の届出 |
| 深夜に、設備を設けてお客様に遊興（ショーやダンスなど）をさせ、お酒を出すクラブなど | 飲食店営業許可＋特定遊興飲食店営業の許可 |

ここで大事なのは、許可や届出は「誰が」「どこで」営業するかに対して出されるということです。このことが、始め方ごとの違いにつながります。

## 1. スケルトン物件から始める

壁や床、設備がない状態の物件を借りて、内装を一から作る方法です。

- **良いところ**：客室の広さや仕切り、照明などを、最初から基準に合わせて設計できます
- **気をつけること**：工事の費用と時間がかかります。工事の前に、用途地域や周りの施設、建物や消防の決まりを確かめておく必要があります

内装を作ってから基準に合わないとわかると、やり直しになります。図面の段階で、許可の基準に合っているかを確かめておくのが確実です。

## 2. 居抜き物件で始める

前のお店の内装や設備が残った物件を借りて始める方法です。

- **良いところ**：内装や設備をそのまま使えるので、費用と準備の期間を抑えられることがあります
- **気をつけること**：前のお店の許可や届出は、新しく営業する人には使えません。飲食店営業許可も、風俗営業の許可も、深夜酒類の届出も、原則として自分で取り直します

前のお店が営業できていたからといって、同じ場所で同じ営業ができるとは限りません。前のお店とは違う営業の形（たとえばバーからキャバクラ）にする場合は、場所や造りの決まりも変わります。

## 3. 今あるお店を事業譲渡で買い取る

営業しているお店を、内装や設備、お客様などとまとめて買い取る方法です。ここは、許可の種類によって扱いが大きく違います。

- **飲食店営業許可**：2023年12月13日から、営業の全部を譲り受けた場合は、保健所への届出によって営業者の地位を引き継げるようになりました。一部だけの譲渡は対象外です
- **風俗営業の許可**：事業譲渡で引き継ぐ制度はありません。引き継げるのは、相続と、会社の合併・分割で公安委員会の承認を受けた場合だけです。買い取った人が、新しく許可を取ります
- **深夜酒類の届出**：届出は営業する人ごとにするものです。買い取った人が、自分で届出をします

「お店を買ったから、すぐ同じように営業できる」と考えるのは危険です。特に風俗営業の許可は、新しく取り直すあいだ、接待をする営業はできません。

## 4. 許可を持っている会社ごと買う

お店を営業している会社の株式を買い取って、会社ごと引き継ぐ方法です。

- **良いところ**：営業している会社そのものは変わらないので、会社が受けている許可や届出は、そのまま会社に残ります
- **気をつけること**：
    - 役員が代わったときは、変更の届出が必要です（会社の役員の氏名・住所が変わった日から20日以内）
    - 新しい役員が、許可を受けられない人（欠格事由）に当たらないかを確かめる必要があります。当たる人が役員になると、許可を取り消されるおそれがあります
    - 2025年の法改正で、親会社などが許可を取り消された会社も、許可を受けられなくなりました。買い手側の会社の状況も関わります
    - 会社の名義は残したまま、実際には別の人がお店を動かしている状態は、名義貸しを疑われるおそれがあります

会社ごと買えば必ずそのまま営業できる、というわけではありません。契約の前に、会社の許可の内容、役員、過去の処分などを確かめることが大切です。

## 5. 間借りや業務委託で営業する

すでに営業しているお店の時間帯や場所を借りて営業する（間借り）、お店の運営を任される（業務委託）といった方法です。

- **良いところ**：自分で物件を借りずに、小さく始められることがあります
- **気をつけること**：許可や届出は、実際に営業する人が受けるものです。他人の許可や届出を借りて営業することはできません

風俗営業の許可を受けた人が、自分の名義で他人に営業させることは、風営法で禁止されています（名義貸しの禁止）。業務委託という形の契約でも、実際には別の人が営業している場合は、名義貸しや無許可営業を疑われるおそれがあります。間借りの場合も、自分が営業するなら、飲食店営業許可などを自分で受ける必要があるかを、保健所や警察署に確かめます。

## 契約の前に確かめたいこと

どの始め方でも、契約を結んだあとに許可が取れないとわかると、取り返しがつきません。次のことは、物件の契約や買収の契約の前に確かめておきます。

- 営業したい形（接待をするか、深夜にお酒を出すか）に必要な許可・届出は何か
- その場所で、その営業ができるか（用途地域、周りの施設）
- 店内の造りが基準に合っているか、合わせられるか
- 前のお店や会社の許可・届出を引き継げるのか、取り直すのか
- 会社ごと買う場合は、役員や過去の処分に問題がないか

風俗営業の許可を取り直す場合の流れは、[風俗営業許可を取る流れ](../how-to-get-entertainment-permit-tokyo/)で、深夜酒類の届出は[深夜酒類の届出の流れ](../late-night-liquor-notification-tokyo/)で確かめられます。

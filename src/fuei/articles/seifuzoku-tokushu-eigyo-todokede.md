この記事は、東京都でデリバリーヘルスや店舗型のお店、アダルト動画の配信サイトなど、性風俗関連特殊営業を始めようと考えている方に向けて、届出の流れと営業できる場所の決まりを説明します。

## 性風俗関連特殊営業とは

風営法では、性風俗に関わる営業を「性風俗関連特殊営業」として、次の3つに分けています。

| 種類 | 主な営業 |
| --- | --- |
| 店舗型性風俗特殊営業 | ソープランド、店舗型ファッションヘルス、ストリップ劇場・個室ビデオ、ラブホテル・モーテル、アダルトショップ、出会い系喫茶 |
| 無店舗型性風俗特殊営業 | デリバリーヘルス（派遣型ファッションヘルス）、アダルトビデオなどの通信販売 |
| 映像送信型性風俗特殊営業 | インターネットで性的な映像を配信する営業 |

スナックやキャバクラの「風俗営業」とは別の決まりで、こちらは**許可ではなく届出**の営業です。届出で始められる一方、種類ごとに、営業できる場所や広告、従業員などについての決まりがあります。

なお、ツーショットダイヤルなどの「電話異性紹介営業」は、同じ警察署の窓口で届け出ますが、性風俗関連特殊営業とは別の営業です。

## 届出の時期と窓口

### 営業を始める日の10日前までに届け出る

届出は、営業を始めようとする日の10日前までに出します。窓口は種類によって次のとおりです。

- **店舗型**：お店ごとに、お店の場所を管轄する警察署
- **無店舗型**：営業の本拠となる事務所の場所を管轄する警察署
- **映像送信型**：事務所の場所を管轄する警察署（ホームページごとに届け出ます）

届出書のほかに、営業の方法を書いた書類、住民票、物件を使う権利があることを示す書類（賃貸借契約書の写しや使用承諾書など）が必要です。会社の場合は、定款や登記事項証明書、役員全員の住民票もそろえます。店舗型は、お店の平面図と周りの略図、お店の業務をまとめる「統括管理者」の住民票も必要です。デリバリーヘルスは事務所の平面図、待機所や受付所を設けるときは、その平面図や使う権利があることを示す書類も求められます。

### 届出確認書を受け取る

届出が受理されると、「届出確認書」が交付されます。届出をしたことを示す大切な書類で、交付には手数料がかかります。広告を出すときや、お店の場所・営業の方法を変えるときにも関わるので、大切に保管しておきます。

なお、届け出た内容に変更があったときや営業をやめるときも、届出が必要です。

## 店舗型の営業できる場所（東京都）

店舗型は、どこでもお店を出せるわけではありません。風営法で、学校・図書館・児童福祉施設などの周り200メートルの範囲では営業できないと定められ、東京都の条例では、入院施設のある病院・診療所もこの基準に加えています。

そのうえで、東京都の条例は、営業の種類ごとに営業できない地域を次のように定めています。

| 営業の種類 | 営業できる地域 |
| --- | --- |
| ソープランド、店舗型ファッションヘルス、デリバリーヘルスの受付所 | 台東区千束四丁目の一部（16〜32番、41〜48番）のみ |
| ストリップ劇場・個室ビデオなど、アダルトショップ、出会い系喫茶 | 商業地域のみ |
| ラブホテル・モーテル（政令で定める構造の施設を設けるもの） | 新宿区歌舞伎町一丁目・新宿二丁目・新宿三丁目、台東区千束四丁目、豊島区西池袋一丁目の、それぞれ決められた番地のみ |
| ラブホテル（政令で定める設備を設けるもの。上の行に当たるものを除く） | 近隣商業地域・商業地域のみ（第一種・第二種文教地区を除く） |

ソープランドや店舗型ヘルスを新しく出せるのは、いわゆる吉原の一部の番地に限られます。さらに、その中でも周りの施設との距離の決まりがあるため、新しくお店を出せる場所はほとんどないのが実情です。決まりができる前から営業しているお店には、法律上の経過措置が関わる場合があります。ただし、営業する人が変わるときや移転するときに、同じ扱いになるとは限りません。

また、東京都では、店舗型性風俗特殊営業のうち法令で定められた営業と、デリバリーヘルスの受付所は、深夜0時から午前6時まで営業できません。

## 無店舗型で気をつけること

デリバリーヘルスは、お店を持たない分、始めやすい営業です。ただ、次の点に気をつける必要があります。

- **受付所を設けるときは場所が限られる**：お客様と対面で受付をする受付所は、店舗型と同じく千束四丁目の一部でしか設けられません
- **待機所や事務所も届け出る**：女性が待機する場所や事務所も、届出の内容に含まれます
- **広告の決まりを守る**：広告や宣伝には、出してよい場所や方法の決まりがあります。広告・宣伝をするときは、18歳未満の方の利用を禁止していることを明らかにする必要があります
- **18歳未満の方は働けない**：年齢は、身分証などで必ず確かめます

## 2025年の改正で禁止された「スカウトバック」

2025年6月28日に施行された風営法の改正で、性風俗店がスカウトから働きたい人の紹介を受け、その紹介料を払うこと（スカウトバック）が禁止されました。

- **対象となる営業**：ソープランド、店舗型ファッションヘルス、デリバリーヘルス（届出をしていないお店も含みます）
- **禁止される行為**：紹介を受けた見返りとして、紹介者や第三者にお金などを渡すこと。「広告費」などの名目でも、2回目以降の支払いでも当たります
- **罰則**：6月以下の拘禁刑か100万円以下の罰金、またはその両方。会社にも罰金が科され、営業停止などの処分を受けることもあります

## お受けできないご依頼

性風俗の営業は、ルールを守れば法律で認められた仕事です。当事務所では、次のようなご依頼はお受けしていません。

- 18歳未満の方を働かせる、または客にする営業
- 届出をしないままの営業や、営業できない場所での営業を続けることを前提にしたご依頼
- 売春にあたるサービスを前提にした営業
- 働くことが認められていない在留資格の方を働かせる営業
- 名義を借りて届出をするご依頼

すでに届出をせずに営業している、名義や在留資格に不安があるといった場合でも、ルールに沿った形に改めるためのご相談はお受けしています。
